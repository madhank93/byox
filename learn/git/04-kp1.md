## What this stage teaches

Trees are directories, and their format mixes text and binary in a way that
punishes assumptions. Each entry is `<mode> <name>\x00<20 raw bytes of SHA>` —
the mode and name are ASCII, the hash is **raw**, not hex, so an entry is not a
line and the object has no line structure at all.

Entries are sorted by name, which is what makes the same directory always hash
to the same tree.

## Go you'll reach for

- `bytes.IndexByte` for the NUL; a fixed 20-byte read after it.
- `encoding/hex.EncodeToString` only when printing.

## Hints

<details><summary>Nudge</summary>

Directory mode is `40000`, not `040000`.
</details>

<details><summary>Approach</summary>

Those 20 raw bytes can contain a newline or a NUL. Index by length, never
scan for a delimiter.
</details>
