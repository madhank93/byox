## Core concept

A git repository is a directory with a known shape: `objects/` for content,
`refs/` for pointers to commits, and `HEAD` naming the branch you are on. `git
init` creates exactly that and nothing else — there is no database, no daemon,
no hidden index beyond files you can read.

`HEAD` starts pointing at a branch that does not exist yet, which is why a
fresh repository has a current branch but no commits.

## Go APIs

- `os.MkdirAll` for `.git/objects` and `.git/refs`.
- `os.WriteFile` for `.git/HEAD` containing `ref: refs/heads/main\n`.
