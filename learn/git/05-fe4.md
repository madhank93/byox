## What this stage teaches

Writing a tree is recursive: each subdirectory is written first, and its hash
becomes an entry in its parent. That makes a repository a **Merkle tree** — a
directory's hash depends on every byte beneath it, so one changed file changes
every hash up to the root, and two identical directories share storage without
anyone deduplicating anything.

## Go you'll reach for

- `os.ReadDir`, sorted by name; recursion into subdirectories.
- The blob writer from stage 3 for files.

## Hints

<details><summary>Nudge</summary>

Skip `.git` itself, or you will hash the repository into itself.
</details>

<details><summary>Approach</summary>

Sort by raw name. Git's ordering has a subtlety for directories, and matching
it exactly is what makes your hashes match real git's.
</details>
