## What this stage teaches

To count a table's rows you first find its **root page**, which is the fourth
column of its `sqlite_schema` row. So answering a query means two lookups:
consult the schema, then go to the page it names.

This is also where you start parsing SQL — enough to pull a table name out of
`SELECT COUNT(*) FROM apples`.

## Go you'll reach for

- The schema reader from stage 3; `(rootpage-1) * pageSize` for the offset.

## Hints

<details><summary>Nudge</summary>

Page numbers are 1-based, so page 1 starts at byte 0.
</details>

<details><summary>Approach</summary>

For a leaf page the cell count *is* the row count. Interior pages arrive at
stage 8.
</details>
