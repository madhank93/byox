## What this stage teaches

Page 1 holds the header **and** the root of `sqlite_schema` — the table that
lists every table, index, view and trigger in the database, along with the
original `CREATE` statement for each. A database describes itself in its own
first page.

Counting tables is counting the cells on that page, and the cell count lives in
the page header. Note the offset trick: page 1's b-tree header starts at byte
**100**, after the file header, while every other page starts at byte 0.

## Go you'll reach for

- A read at offset 100; `binary.BigEndian.Uint16(page[3:5])` for the cell count.

## Hints

<details><summary>Nudge</summary>

The first byte of the page header is the type: `0x0d` is a table leaf.
</details>
