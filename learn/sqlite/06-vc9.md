## What this stage teaches

Several columns, joined by `|`, in the order the **query** asked for — not the
order they sit in the record. That distinction is projection: the stored layout
and the result shape are independent, which is why `SELECT b, a` is a
reordering rather than an error.

## Go you'll reach for

- A slice of column indexes built from the query, applied per row.

## Hints

<details><summary>Nudge</summary>

Resolve each requested name to its index once, before scanning rows.
</details>

<details><summary>Approach</summary>

Resolve every requested name to an index before scanning, not inside the
row loop. Then each row is a lookup per requested column rather than a
search.
</details>
<details><summary>The API</summary>

`strings.Join(values, "|")` — the separator is a pipe with no spaces.
</details>
