## What this stage teaches

Your first parse. The request line is three space-separated fields —
`METHOD TARGET VERSION` — and the target is what you route on. This is also the
first stage with two possible responses, which makes it the first stage that can
be *wrong* rather than merely absent.

## Go you'll reach for

- `bufio.NewReader(conn)` then `ReadString('\n')` for the first line.
- `strings.Fields` or `strings.Split(line, " ")` to pull the target out.
- `strings.TrimSpace` — the line still carries its `\r\n`.

## Hints

<details><summary>Nudge</summary>

Split on spaces, take the middle field. Compare it to `/` exactly — `/index`
is not `/`.
</details>

<details><summary>Approach</summary>

Create the `bufio.Reader` once and keep it: later stages read headers and a body
from the same connection, and a second reader would lose whatever the first
buffered.
</details>

<details><summary>The API</summary>

`HTTP/1.1 404 Not Found\r\n\r\n` is the other response. Reason phrases are not
parsed by clients, but the tester compares the whole status line — match it
exactly.
</details>
