## Core concept

The smallest legal HTTP response. A status line, then a blank line — and both
line endings are CRLF (`\r\n`), never a bare `\n`. The blank line is not
decoration: it is the marker that says "headers are over", and without it the
client keeps waiting for more headers.

## Go APIs

- `conn.Write([]byte("HTTP/1.1 200 OK\r\n\r\n"))`

## Hints

<details><summary>Nudge</summary>

Count the CRLFs. A response with no headers still has two: one ending the
status line, one ending the (empty) header block.
</details>

<details><summary>Approach</summary>

You do not have to read the request yet. Accept, write the fixed response,
close.
</details>

<details><summary>Implementation</summary>

`net.Conn` is an `io.Writer`. A raw string literal in Go keeps `\r\n` literal,
so use an interpreted string (double quotes) here.
</details>
