## What this stage teaches

Most HTTP headers are lists, comma-separated with optional whitespace, and
`Accept-Encoding` is the one where that bites. `encoding-1, gzip, encoding-2`
means the client can take gzip even though gzip is neither first nor alone.

## Go you'll reach for

- `strings.Split(value, ",")` then `strings.TrimSpace` on each part.
- `slices.ContainsFunc`, or a plain loop.

## Hints

<details><summary>Nudge</summary>

Substring matching on the raw header value looks like it works and is wrong —
`x-gzip-2` contains `gzip`.
</details>

<details><summary>Approach</summary>

Split into entries, trim each, compare each for equality. Unknown entries are
simply skipped, not errors.
</details>

<details><summary>The API</summary>

Real `Accept-Encoding` values can carry quality weights (`gzip;q=0.5`). The
tester does not send them, but cutting at `;` before comparing costs one line
and makes the parser honest.
</details>
