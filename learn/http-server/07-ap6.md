## What this stage teaches

Serving files introduces state that lives outside the process — a directory
passed on the command line — and the first genuinely security-shaped decision in
the course: a request path is untrusted input, and joining it to a directory
naively lets a client walk out of that directory.

## Go you'll reach for

- `flag.String("directory", "", "")` or a manual `os.Args` scan.
- `filepath.Join(dir, name)` — it cleans `..` segments as it joins.
- `os.ReadFile`, and `os.IsNotExist(err)` to map a missing file to 404.
- Content type `application/octet-stream` for arbitrary files.

## Hints

<details><summary>Nudge</summary>

Missing file is a 404, not a 500. Everything else is a 200 with the file's bytes
and its byte length.
</details>

<details><summary>Approach</summary>

Take only the last path segment of the request target, or join and then verify
the result still has the served directory as its prefix. Do not concatenate
strings with `+`.
</details>

<details><summary>The API</summary>

`os.ReadFile` returns `[]byte` — write it straight to the connection. Don't
convert to `string` and back; binary files will survive it in Go, but the habit
breaks elsewhere.
</details>
