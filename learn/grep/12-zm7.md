## What this stage teaches

`(cat|dog)` looks like a choice between two things and is really a choice
between two *continuations*. You cannot pick the branch that matches locally
and move on — the failure may come **after** the group, and the other branch
might have avoided it. So each alternative is tried with the whole remainder of
the pattern following it.

That is why alternation cannot be implemented by matching branches in
isolation, and why it needs the same backtracking `+` did.

```
pattern  (cat|dog)s      input  dogs

  try branch "cat" ---> matches? no  -----------+
                                                |
  try branch "dog" ---> matches at 0..3         |
        |                                       |
        +-> continuation "s" at 3 ---> MATCH    |
                                                |
  had "s" failed, control returns here <--------+
  and the NEXT branch is tried

this is why a branch cannot be chosen in isolation: the failure may happen
after the group, and the other branch might have avoided it.
```

## Go you'll reach for

- A group element holding alternatives, each tried with a continuation.
