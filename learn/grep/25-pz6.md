## Core concept

Every matching line prints, not just the first — the search covers the whole
input regardless of how early it succeeds. Exiting at the first match would
give the right status and the wrong output.

## Go APIs

- The existing per-line loop, with no early return.

## Hints

<details><summary>Nudge</summary>

Keep scanning after a match; only the exit code is decided at the end.
</details>
