## Core concept

`?` is `+` with a smaller range: try one, then try zero. Same greedy order,
same backtracking machinery — which is the point. If `+` was written as
"try counts from high to low", `?` is that with a maximum of one.

## Go APIs

- The same count-then-retreat loop, bounded at 1.

## Hints

<details><summary>Nudge</summary>

Zero repetitions must still let the rest of the pattern match at the same
position.
</details>

<details><summary>Approach</summary>

Try one repetition, then zero. Both must recurse on the remainder — the
zero case is not a no-op, it is a different match attempt at the same
position.
</details>
<details><summary>Implementation</summary>

The same retreat loop as `+`, with the count capped at 1.
</details>
