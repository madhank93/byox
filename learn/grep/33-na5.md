## What this stage teaches

`--color=auto` colours only when stdout is a **terminal**, and pipes plain text
otherwise. That is how `grep` in your shell is colourful while
`grep x f > out` produces a clean file — the program asks what it is writing
to and adapts.

A good note to end on: the last stage of a regex engine is not about regexes at
all, but about a program behaving well in the environment it was run in.

## Go you'll reach for

- `os.Stdout.Stat()`, checking `mode & os.ModeCharDevice`.

## Hints

<details><summary>Nudge</summary>

A pipe or a file is not a character device; a terminal is.
</details>

<details><summary>Approach</summary>

Test it both ways: run it, then pipe it through `cat` and confirm the escapes
are gone.
</details>
