## What this stage teaches

`\d` is the first element that matches a **set** rather than a specific
character. The generalisation worth making now: an element is a predicate over
one byte, and a literal is just the predicate "equals this byte". Model it that
way and `\w`, `[abc]` and `.` are all the same shape.

## Go you'll reach for

- A parsed element type carrying a `matches(b byte) bool`.

## Hints

<details><summary>Nudge</summary>
