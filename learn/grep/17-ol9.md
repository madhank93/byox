## What this stage teaches

grep is **line-oriented**: the file is split on newlines and each line is
matched independently, which is why `^` and `$` mean line boundaries rather
than file boundaries. Every matching line is printed, not just the first.

## Go you'll reach for

- `bytes.Split(content, []byte("\n"))`, trimming a trailing empty element.

## Hints

<details><summary>Nudge</summary>

A file with no final newline still has a last line.
</details>

<details><summary>Approach</summary>

Split on newlines and match each line independently — that is why `^` and `$`
mean line boundaries here.
</details>
