## Core concept

`*` completes the classic trio. It is `+` with a floor of zero, and it makes
explicit what the retreat loop already implied: a quantifier is a **range** of
acceptable counts, tried greedily from the top.

## Go APIs

- The same loop, retreating to 0.

## Hints

<details><summary>Nudge</summary>

`a*` matches the empty string, so it never fails on its own.
</details>

<details><summary>Approach</summary>

`*` is `+` with the floor moved to zero, so the retreat loop ends at 0
rather than 1.
</details>
<details><summary>Implementation</summary>

Because zero repetitions always succeed, `a*` alone can never fail — the
result depends entirely on what follows it.
</details>
