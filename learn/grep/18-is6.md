## What this stage teaches

With more than one file, every matching line is prefixed `filename:` — and with
exactly one file it is not. The output format depends on the *number of
inputs*, which is a small piece of interface design: the prefix appears only
when it disambiguates something.

## Go you'll reach for

- A `prefixWithFilename := len(files) > 1` decision made once.

## Hints

<details><summary>Nudge</summary>

Files are searched in the order given.
</details>

<details><summary>Approach</summary>

Decide the prefix once from the number of inputs, not per line.
</details>
