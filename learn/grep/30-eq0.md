## Core concept

Several highlighted spans in one line, and the detail that bites: inserting
escape sequences **changes the offsets** of everything after them. Build the
output by walking the original line and copying between spans, rather than
splicing into a string you are simultaneously lengthening.

## Go APIs

- All match spans first, then one pass building the output.

## Hints

<details><summary>Nudge</summary>
