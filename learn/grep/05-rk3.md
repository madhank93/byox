## What this stage teaches

`[^abc]` matches any character *not* in the set — and note it still consumes
one character. Negation inverts the predicate, it does not make the element
optional or zero-width, which is a distinction that matters once quantifiers
arrive.

## Go you'll reach for

- A `negated bool` on the group, flipping the membership test.

## Hints

<details><summary>Nudge</summary>

The `^` is only special immediately after the `[`.
</details>

<details><summary>Approach</summary>

Negation inverts the predicate but still consumes one character — it is not
zero-width and not optional.
</details>
