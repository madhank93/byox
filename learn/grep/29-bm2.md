## Core concept

Colour is text. `\033[01;31m` turns on bold red, `\033[m` turns everything off,
and the terminal interprets those bytes as commands rather than printing them.
Highlighting a match is wrapping its span in those two sequences — which is why
piping coloured output into a file gives you a file full of escape codes.

## Go APIs

- The match span from stage 26, and a rebuilt line with the escapes inserted.
