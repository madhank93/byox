## What this stage teaches

`.` is the predicate that always says yes. It needs no special handling
anywhere — which is a good check on the element abstraction: if `.` requires a
branch of its own, the design has predicates and characters muddled together.

## Go you'll reach for

- An element whose `matches` returns true.
