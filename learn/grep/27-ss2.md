## What this stage teaches

Finding every match in a line means searching again from where the last one
ended. The trap is a pattern that can match **empty** — `a*` matches nothing at
every position, and a loop that does not advance past a zero-width match spins
forever.

## Go you'll reach for

- A `findMatch(line, pattern, from)` taking a start offset.
- An advance of at least one byte when a match is empty.

## Hints

<details><summary>Nudge</summary>

An anchored pattern can only match at offset 0, so the search must not restart
it later.
</details>
