## Core concept

`-r` turns a directory into a list of files. Recursion always implies the
filename prefix, since a directory search has more than one input by nature.

## Go APIs

- `filepath.WalkDir`, collecting non-directory entries.

## Hints

<details><summary>Nudge</summary>

Paths are reported as walked, so the prefix includes the directory.
</details>

<details><summary>Approach</summary>

Collect the file list first, then run the existing per-file search over it.
Recursion is a change to the inputs, not to the matcher.
</details>
<details><summary>Implementation</summary>

`filepath.WalkDir` with a callback that appends when `!d.IsDir()`.
</details>
