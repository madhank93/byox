## What this stage teaches

`[abc]` is the first element whose *parsing* is non-trivial — it spans several
characters, so the pattern can no longer be walked one byte at a time. This is
where a real parse step starts to earn its place over ad-hoc indexing.

## Go you'll reach for

- A scan to the closing `]`, collecting the members.

## Hints

<details><summary>Nudge</summary>

Store the set and match membership.
</details>

<details><summary>Approach</summary>

Parsing the pattern into elements once, before matching, beats re-scanning it
at every position — and the quantifier stages need that structure anyway.
</details>
