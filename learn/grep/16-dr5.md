## What this stage teaches

Input moves from stdin to a named file. The engine does not change at all — a
line is a line — but the program grows a second input mode, and it is worth
keeping the matcher unaware of where its bytes came from.

## Go you'll reach for

- `os.ReadFile` when a filename argument is present.
