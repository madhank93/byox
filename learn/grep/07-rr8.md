## What this stage teaches

`^` is the first element that **consumes nothing**. It asserts about a
position, and it changes the outer loop rather than the inner one: an anchored
pattern is tried at position 0 only, instead of at every start.

## Go you'll reach for

- A flag stripped from the pattern, disabling the sliding start.

## Hints

<details><summary>Nudge</summary>

`^` is only an anchor at the start of the pattern.
</details>

<details><summary>Approach</summary>

An anchor changes the outer loop, not the inner one: try position 0 only
instead of sliding.
</details>
