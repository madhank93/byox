## Core concept

A detail that trips people: `Fetch` identifies topics by **UUID**, while
`DescribeTopicPartitions` uses names. Kafka moved to ids so a topic can be
deleted and recreated without a stale consumer silently reading the new one.

An unknown id gets error **100**, `UNKNOWN_TOPIC_ID` — a different code from the
name-based one.

## Go APIs

- A lookup keyed by `[16]byte` UUID.

## Hints

<details><summary>Nudge</summary>

Index your metadata both ways — by name for Describe, by UUID for Fetch.
</details>

<details><summary>Approach</summary>

Index topics by UUID as well as by name: Fetch addresses them by id, Describe
by name.
</details>
