## What this stage teaches

A Kafka broker is a TCP server on port 9092. Nothing Kafka-specific yet — but
worth noting what a broker *is*: a process that owns some partitions' log files
on disk and answers requests about them. Everything in this course is either
wire format or those files.

## Go you'll reach for

- `net.Listen("tcp", "0.0.0.0:9092")` and an accept loop.
