## What this stage teaches

Writing, and the symmetry pays off: the record batch arrived in exactly the
format the log stores, so producing is **appending the request's bytes
verbatim**. The same identity that made `Fetch` a file read makes `Produce` a
file append.

Open with `O_APPEND` so every write lands at the end regardless of position —
that is what makes concurrent appends safe.

## Go you'll reach for

- `os.MkdirAll` for the partition directory.
- `os.OpenFile(path, os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0644)`.

## Hints

<details><summary>Nudge</summary>

The path is `/tmp/kraft-combined-logs/<topic>-<partition>/00000000000000000000.log`.
</details>

<details><summary>Approach</summary>

Round-trip it: produce, then fetch. The bytes should come back identical.
</details>

<details><summary>The API</summary>

`os.OpenFile(path, os.O_CREATE|os.O_APPEND|os.O_WRONLY, 0644)`. Append mode
is what makes concurrent produces safe without a lock.
</details>
