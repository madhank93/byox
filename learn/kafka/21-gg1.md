## What this stage teaches

A successful produce answers with the **base offset** the records were written
at. That number is the producer's receipt and the consumer's address — the same
integer identifies the record forever, because the log is append-only and
nothing is ever renumbered.

## Go you'll reach for

- A per-partition response carrying error 0 and the base offset.
