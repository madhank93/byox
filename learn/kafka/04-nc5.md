## Core concept

Kafka's protocol is versioned **per API**, and the version decides which fields
exist in the request and the response. An unsupported version is not a parse
failure — it is a correctly framed response carrying error code **35**,
`UNSUPPORTED_VERSION`.

That distinction is what lets old clients and new brokers negotiate rather than
hang up on each other.

## Go APIs

- A range check on `api_version`; a 2-byte error code in the response.

## Hints

<details><summary>Nudge</summary>

ApiVersions supports versions 0 to 4; anything else is error 35.
</details>

<details><summary>Approach</summary>

Range-check the version and answer with error 35 in a correctly framed
response — an unsupported version is not a parse failure.
</details>
