## What this stage teaches

Before a client will send an API, it has to see it advertised. Adding an entry
to the `ApiVersions` response — api key 75, with its supported version range —
is the handshake step that unlocks the next four stages.

## Go you'll reach for

- A second entry in the api_keys array; remember its tag buffer.

## Hints

<details><summary>Nudge</summary>

Each entry is api key, min version, max version, then the tag byte.
</details>

<details><summary>Approach</summary>

One more entry in the api_keys array, with its own tag buffer after it.
</details>
