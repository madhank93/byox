## What this stage teaches

`ApiVersions` is how a client discovers what the broker speaks, so it must work
before anything else can. It is also the first **flexible** response, which
changes the primitives underneath you:

- **Compact arrays** encode length as an unsigned varint of `actual + 1`, so
  `0` means null and `1` means empty.
- **Tagged fields**: a varint count of optional trailing fields at the end of
  the header *and* of every struct. It is almost always `0` — but the byte must
  be there, and omitting it shifts everything after it.

## Go you'll reach for

- An unsigned varint writer; a trailing zero byte per struct.

## Hints

<details><summary>Nudge</summary>

An array of one entry is written as the varint `2`.
</details>

<details><summary>Approach</summary>

Write `appendCompactArrayLen` and `appendTagBuffer` helpers now. Every
remaining stage uses them, and a missing tag byte is invisible until the client
misparses something three fields later.
</details>
