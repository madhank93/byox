## What this stage teaches

The `Fetch` response skeleton with nothing in it: a throttle time, a top-level
error code, a session id, and an empty topic array. Getting the empty case
exactly right first is worth it — every later Fetch stage adds to this shape,
and a missing field here is a misparse there.

## Go you'll reach for

- A compact array of length 0, written as the varint `1`.

## Hints

<details><summary>Nudge</summary>

Don't forget the response header's tag buffer as well as the body's.
</details>

<details><summary>Approach</summary>

Get the empty response exactly right first — every later Fetch stage adds to
this skeleton.
</details>
