## Core concept

The last capability to advertise: api key 0, `Produce` — the very first API
Kafka ever defined, and the one that turns the broker from a reader into a
writer.

## Go APIs

- A fourth entry in the api_keys array.

## Hints

<details><summary>Nudge</summary>

Api key 0. The numbering follows the order APIs were added.
</details>
