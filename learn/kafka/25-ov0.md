## What this stage teaches

The full shape: topics containing partitions containing record batches, each
partition acknowledged independently. Nothing new — it is the previous stage
one level of nesting out, and the response mirrors the request's structure
exactly.

Worth a pause at the end: the broker you built reads its own cluster state from
a log, serves fetches by handing over file bytes untouched, and produces by
appending them back. The wire format and the storage format being the same
thing is the idea the whole system is built on.

- The nested loop, and the helpers from stage 5 for every array and tag buffer.
