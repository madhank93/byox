## Core concept

Several record batches sit back to back in the segment file, and they are
returned together. Batching is the other half of Kafka's throughput story: the
per-message overhead is amortised across a batch, on disk and on the wire
alike.

## Go APIs

- The whole file's bytes, unchanged.

## Hints

<details><summary>Nudge</summary>

Returning the file as-is already contains every batch in order.
</details>

<details><summary>Approach</summary>

Return the whole segment file — consecutive batches are already laid out
back to back in it.
</details>
<details><summary>Implementation</summary>

A missing log file means an empty partition, not an error: send a null
records field and error code 0.
</details>
