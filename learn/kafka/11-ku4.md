## What this stage teaches

A topic is a set of partitions, and partitions are the unit of parallelism and
of ordering: Kafka guarantees order **within** a partition, never across them.
Listing them all means collecting every partition record that names this
topic's UUID.

## Go you'll reach for

- A grouping of partition records by topic UUID.

## Hints

<details><summary>Nudge</summary>

Report them in partition-id order.
</details>

<details><summary>Approach</summary>

Index partition records by the topic UUID they name, so listing a topic's
partitions is a map lookup rather than a rescan.
</details>
<details><summary>The API</summary>

Report them in partition-id order; the metadata log's order is not
guaranteed.
</details>
