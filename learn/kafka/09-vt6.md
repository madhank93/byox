## What this stage teaches

`DescribeTopicPartitions` for a topic that does not exist returns error code
**3**, `UNKNOWN_TOPIC_OR_PARTITION`, inside a normal response — an error about
the data, not about the request.

This is also where **compact strings** appear: length as an unsigned varint of
`actual + 1`, so a 5-character name is prefixed with `6`.

## Go you'll reach for

- A compact string reader and writer.
- A zero UUID for the unknown topic's id.

## Hints

<details><summary>Nudge</summary>

The topic name is echoed back alongside the error.
</details>

<details><summary>Approach</summary>

Echo the requested name back alongside error 3 and a zero UUID.
</details>
