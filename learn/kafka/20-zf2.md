## What this stage teaches

A produce to a topic or partition that does not exist is rejected with error
**3**, and nothing is written. Validating before touching the log is what keeps
a bad request from leaving a partially written segment behind — the log is
append-only, so there is no undo.

## Go you'll reach for

- A metadata lookup for both the topic and the partition id.

## Hints

<details><summary>Nudge</summary>

A known topic with an unknown partition is the same error.
</details>

<details><summary>Approach</summary>

Validate before touching the log. An append-only file has no undo.
</details>
