## What this stage teaches

Every scanner ends the same way: with an EOF token. It is not padding — the
parser needs a token to look at when the input runs out, and having one means
"end of input" is handled by the same code path as every other token rather
than by a special case at every call site.

## Go you'll reach for

- `os.Args` to read the `tokenize` subcommand and filename.
- `os.ReadFile` for the source.

## Hints

<details><summary>Nudge</summary>

An empty file produces exactly one line of output: `EOF  null`.
</details>

<details><summary>Approach</summary>

Set up the command dispatch now — later stages add `parse`, `evaluate` and
`run` alongside `tokenize`.
</details>
