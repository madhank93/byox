## Core concept

Two different checks that both concern arguments. **Arity** is a runtime error —
`Expected 2 arguments but got 1.` — because which function is being called is
only known once the callee is evaluated. The 255-argument limit is a *parse*
error, because it is a property of the source text alone.

## Go APIs

- An arity comparison in the call evaluation.
- A count check in the argument-parsing loop.

## Hints

<details><summary>Nudge</summary>

The arity message is exact, singular/plural included.
</details>

<details><summary>Approach</summary>

Two different phases: arity is checked at runtime, the argument-count limit
at parse time. Put each check where its information lives.
</details>
