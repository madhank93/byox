## What this stage teaches

`Foo()` constructs an instance — and notice the syntax: Lox has no `new`,
because a class is simply **callable**, implementing the same `LoxCallable`
interface functions do. Calling it returns an instance instead of running a
body.

## Go you'll reach for

- `LoxClass` implementing `Call`, returning a `LoxInstance`.

## Hints

<details><summary>Nudge</summary>

An instance prints as `Foo instance`.
</details>

<details><summary>Approach</summary>

Make `LoxClass` implement the same callable interface a function does; the
call returns an instance instead of running a body.
</details>
