## What this stage teaches

`+` means two things depending on what it is given: numeric addition for two
numbers, concatenation for two strings. In a dynamically typed language that
decision happens **at runtime**, by inspecting the operand values — there is no
type checker to settle it earlier.

Lox refuses to mix: `"a" + 1` is an error, not a coercion. Languages that
coerce here are the ones where `1 + "1"` surprises people.

## Go you'll reach for

- A type switch on both operands inside the `+` case.

## Hints

<details><summary>Nudge</summary>

Both `float64` → add. Both `string` → concatenate. Anything else → the next
stages make it an error.
</details>
