## What this stage teaches

State arrives. An **environment** maps names to values, `var` puts a name in
it, and an identifier expression reads one back. This is the structure that
scoping, closures and `this` are all built on, so it is worth building
deliberately rather than as a bare map at the top of the file.

## Go you'll reach for

- An `Environment` type wrapping `map[string]interface{}`.
- A `VarStmt` and a `VariableExpr`.

## Hints

<details><summary>Nudge</summary>

`var a = 1; print a;` prints `1`.
</details>

<details><summary>Approach</summary>

Give the environment `Define` and `Get` methods now — later stages add
`Assign` and a parent pointer, and callers should not have to change.
</details>
