## What this stage teaches

A subclass method with the same name wins, because lookup checks the class's
own methods **before** consulting the superclass. Overriding is not a feature
you add — it is what the lookup order already means.

## Go you'll reach for

- Nothing new, if `FindMethod` checks `c.Methods` first.

## Hints

<details><summary>Nudge</summary>

The overriding method still has its own `this`, bound to the same instance.
</details>

<details><summary>Approach</summary>

Check the class's own methods first; overriding is what that order already
means.
</details>
