## What this stage teaches

Two more single-character tokens. The point is that the `switch` scales: each
new punctuation mark is a case, and nothing else in the scanner changes. If
adding a token means touching more than one place, the structure is wrong.

## Go you'll reach for

- Two more cases: `LEFT_BRACE`, `RIGHT_BRACE`.
