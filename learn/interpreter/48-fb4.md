## What this stage teaches

A block gets its own environment whose **parent** is the enclosing one, and
lookup walks that chain outward until it finds the name. That single pointer
turns a flat map into lexical scoping: an inner `var a` shadows an outer one,
and the outer value is intact again when the block ends.

Assignment walks the same chain — which is why assigning inside a block changes
the outer variable, while declaring inside it does not.

## Go you'll reach for

- A `parent *Environment` field; `Get`/`Assign` recursing into it.
- A fresh child environment per block, restored afterwards.

## Hints

<details><summary>Nudge</summary>

Restore the previous environment even when the block errors — otherwise the
interpreter is left in an inner scope.
</details>

<details><summary>Approach</summary>

This chain walk is correct but not complete: stage 67 replaces the search with
a precomputed hop count, because a search can find the wrong binding when a
closure is involved.
</details>
