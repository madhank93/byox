## What this stage teaches

`*` and `/` bind tighter than `+` and `-`, and recursive descent expresses that
as **layers**: each precedence level is a function that calls the next tighter
one. The grammar's shape becomes the code's shape, which is why adding an
operator later is a one-function change.

Left associativity — `1/2/3` is `(1/2)/3` — comes from a loop, not recursion:
parse one operand, then keep folding the result into a new binary node.

## Go you'll reach for

- A `BinaryExpr` with left, operator, right.
- `factor()`: parse a `unary()`, then `for` while the next token is `*` or `/`.

## Hints

<details><summary>Nudge</summary>

`16 * 38 / 58` prints as `(/ (* 16.0 38.0) 58.0)`.
</details>

<details><summary>Approach</summary>

Build the node with the accumulated left side each iteration. Recursing instead
would make it right-associative and give the wrong answer for division.
</details>
