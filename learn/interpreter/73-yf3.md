## What this stage teaches

`instance.field` reads and `instance.field = value` writes, and Lox instances
are **open**: assigning to a property that does not exist creates it. There is
no fixed shape declared anywhere, so an instance is a name-to-value map with a
class attached.

Property access also needs the assignment trick again — `a.b = c` parses `a.b`
as a get, then converts it to a set when `=` follows.

## Go you'll reach for

- `GetExpr` and `SetExpr` nodes; a `fields map[string]interface{}` on the instance.
- `Undefined property 'x'.` when reading something absent.

## Hints

<details><summary>Nudge</summary>

Reading a missing property errors; writing one succeeds.
</details>

<details><summary>Approach</summary>

Parse `a.b` as a get, then convert it to a set when `=` follows — the same
reinterpretation trick assignment used.
</details>
