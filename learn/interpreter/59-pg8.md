## What this stage teaches

`fun` declares a function, and the declaration **binds a value** to a name like
`var` does. Functions are ordinary values in Lox: you can pass them, return
them and store them, which is what makes stage 63 free.

Calling one executes its body in a fresh environment, then returns `nil` unless
the body says otherwise.

## Go you'll reach for

- A `FunctionStmt` and a `LoxFunction` implementing `LoxCallable`.

## Hints

<details><summary>Nudge</summary>

A function with no explicit return evaluates to `nil`.
</details>

<details><summary>Approach</summary>

Executing the declaration binds a callable value to the name, exactly as
`var` binds any other value.
</details>
