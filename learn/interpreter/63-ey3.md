## What this stage teaches

Passing a function as an argument and returning one from a function. If
functions are values held in environments like any other, this needs no new
code — which is the payoff for making them first class at stage 59 rather than
a special table of named routines.

## Go you'll reach for

- Nothing new.

## Hints

<details><summary>Nudge</summary>

A function name in argument position is just a variable read.
</details>

<details><summary>Approach</summary>

If a declared function is stored in the environment like any other value,
passing and returning one needs no new code.
</details>
<details><summary>The API</summary>

A function used as an argument is parsed as a plain variable expression —
the call syntax only appears where it is actually called.
</details>
