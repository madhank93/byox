## What this stage teaches

`this` outside a method is a static error, caught by the resolver's class
context — the same mechanism that caught top-level `return`. The resolver now
tracks two contexts, function and class, and each one guards a keyword.

## Go you'll reach for

- A `currentClass` enum alongside `currentFunction`.
