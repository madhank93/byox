## Core concept

The last stage, and it closes the resolver's story. `super` outside a class is
one error; `super` in a class with no superclass is another; and a bare `super`
without a property access is a syntax error. Three checks, all static, all
reading the class context the resolver has been tracking since stage 76.

Finishing here is worth a moment: characters became tokens, tokens a tree, the
tree got a static pass, and the pass made evaluation both correct and faster.
Every phase stayed separate, which is why the last feature in the language was
still a contained change.

## Go APIs

- The `currentClass` enum, extended with a subclass state.

## Hints

<details><summary>Nudge</summary>

`Can't use 'super' outside of a class.` and

</details>

<details><summary>Approach</summary>

Extend the class context with a subclass state, so "in a class" and "in a
class with a superclass" are distinguishable.
</details>
