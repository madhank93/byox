## Core concept

The first backwards jump. The condition is re-evaluated **every iteration** —
if it were evaluated once, the loop would either never run or never stop. In a
tree-walking interpreter that is a Go `for` loop around a recursive execute
call, which means Lox's loops sit on Go's stack.

## Go APIs

- A `WhileStmt`; `for isTruthy(evaluate(cond)) { execute(body) }`.

## Hints

<details><summary>Nudge</summary>

The body is a single statement — usually a block.
</details>

<details><summary>Approach</summary>

Re-evaluate the condition every iteration — hoisting it out gives a loop
that either never runs or never stops.
</details>
