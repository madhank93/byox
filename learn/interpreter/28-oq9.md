## What this stage teaches

A grouping evaluates to whatever is inside it. The node mattered for parsing —
it recorded how the source grouped — but carries no value of its own, so
evaluation just recurses through it.

## Go you'll reach for

- A `GroupingExpr` case that returns `evaluate(inner)`.

</details>

<details><summary>Approach</summary>
