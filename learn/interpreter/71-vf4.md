## Core concept

A class declaration binds a name to a **class object** — a runtime value, like
a function. Printing a class prints its name. Nothing about instances yet; this
stage is about classes being ordinary values that live in environments.

## Go APIs

- A `ClassStmt` and a `LoxClass` with a name.

## Hints

<details><summary>Nudge</summary>

`class Foo {} print Foo;` prints `Foo`.
</details>

<details><summary>Approach</summary>

name.
</details>
