## What this stage teaches

Calling something that is not callable: `"not a function"()`. The check is
`Can only call functions and classes.` and it happens at runtime, because in a
dynamically typed language the callee's type is only known once evaluated.

## Go you'll reach for

- A type assertion to `LoxCallable` on the evaluated callee.

## Hints

<details><summary>Nudge</summary>

Check callability *before* checking arity — you cannot ask a string its arity.
</details>
