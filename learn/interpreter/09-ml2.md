## Core concept

`/` is the first character whose meaning depends on what follows: a division
operator, or the start of a `//` comment that runs to the end of the line. And
a comment produces **no token at all** — the scanner consumes input and emits
nothing, which is a case the loop has to allow for.

## Go APIs

- `match('/')` to detect the second slash.
- A skip loop: advance while the current character is not `\n`.

## Hints

<details><summary>Nudge</summary>

Stop at the newline, don't consume it — the next stage counts lines.
</details>

<details><summary>Approach</summary>

Guard the skip loop against running off the end of the source; a comment on the
last line has no trailing newline.
</details>
