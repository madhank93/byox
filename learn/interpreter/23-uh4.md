## What this stage teaches

`<` `<=` `>` `>=`, one layer looser than `+`/`-` — so `1 + 2 < 4` groups as
`(1 + 2) < 4`, which is what anyone reading it expects. Same loop, same shape,
one more level.

## Go you'll reach for

- `comparison()`: a `term()`, then a loop over the four relational operators.

## Hints

<details><summary>Nudge</summary>

`83 < 99 < 115` prints `(< (< 83.0 99.0) 115.0)` — legal to parse, and a type
error to evaluate, later.
</details>
