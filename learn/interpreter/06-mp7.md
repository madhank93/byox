## What this stage teaches

`=` and `==` share a first character, so the scanner needs one character of
lookahead and the **maximal munch** rule: when two tokens could match, take the
longer one. `==` is never two `=` tokens.

## Go you'll reach for

- A `match(expected byte) bool` helper that consumes the next character only
  if it matches.

## Hints

<details><summary>Nudge</summary>

`case '=': if match('=') { EQUAL_EQUAL } else { EQUAL }`.
</details>

<details><summary>Approach</summary>

Write `match` once. The next two stages are the same shape with `!`, `<`, `>`.
</details>
