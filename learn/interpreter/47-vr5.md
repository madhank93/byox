## What this stage teaches

`{ ... }` groups statements into one statement, so anywhere a single statement
is allowed you can put many. Parsing is a loop until `}` or EOF; the scoping
consequences arrive next stage.

## Go you'll reach for

- A `BlockStmt` holding `[]Stmt`.

## Hints

<details><summary>Nudge</summary>

An unclosed block is a syntax error at EOF.
</details>
