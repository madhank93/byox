## What this stage teaches

Identifiers are the open-ended token type: a letter or underscore followed by
any run of letters, digits and underscores. The scanner takes the longest run
it can, which is the same maximal-munch instinct as `==`, applied to a
variable-length token.

## Go you'll reach for

- A helper for "is letter or underscore" and one for "is alphanumeric".
- A loop consuming while alphanumeric.

## Hints

<details><summary>Nudge</summary>

`IDENTIFIER foo null` — an identifier has no literal value at scan time.
</details>
