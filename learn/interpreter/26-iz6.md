## What this stage teaches

The third phase: the tree becomes a **value**. `evaluate` walks the tree and
returns a Go value for it, and printing that value is a separate concern from
printing the tree — which is why `true` prints as `true` here and printed as
`true` in the parser for different reasons.

## Go you'll reach for

- `evaluate(e Expr) interface{}` with a type switch.
- A `stringify` that turns a value into Lox's output form.

## Hints

<details><summary>Nudge</summary>

Only three values matter at this stage; `nil` prints as `nil`.
</details>

<details><summary>Approach</summary>

Separate `evaluate` from `stringify`. Every later stage adds cases to one or
the other, rarely both.
</details>
