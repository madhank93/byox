## Core concept

Malformed control flow — a missing `)`, a missing condition, a stray `else` —
reported as syntax errors with exit 65. Every `consume` call in the control
flow parsers is a place where a specific, useful message belongs.

## Go APIs

- Targeted messages: `Expect ')' after if condition.` and friends.

## Hints

<details><summary>Nudge</summary>

Name what was expected and where, not just "syntax error".
</details>

<details><summary>Approach</summary>

Name what was expected at each `consume` site. "Expect ')' after if
condition" is worth far more than a generic parse error.
</details>
