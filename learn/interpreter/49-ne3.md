## What this stage teaches

The first control flow: evaluate the condition, and execute the branch only if
it is truthy. Note what does *not* happen — the untaken branch is never
evaluated, which is the whole point and the first time the tree walk skips a
subtree.

## Go you'll reach for

- An `IfStmt` with a condition and a then-branch.
- The `isTruthy` helper from stage 29.

## Hints

<details><summary>Nudge</summary>

The parentheses around the condition are required by the grammar.
</details>

<details><summary>Approach</summary>

Evaluate the condition, then execute the branch only if it is truthy — the
untaken branch must never be evaluated.
</details>
