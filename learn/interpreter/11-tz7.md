## Core concept

An error message is only useful if it says *where*. The scanner keeps a line
counter, incremented on every newline, and stamps it onto each error it
reports. This is the smallest possible version of source positions — real
compilers track line and column, and often a byte range.

## Go APIs

- A `line` counter starting at 1, `line++` in the newline case.

## Hints

<details><summary>Nudge</summary>

Start at 1, not 0 — humans count lines from one.
</details>

<details><summary>Approach</summary>

Store the line on each token as well as on errors. The parser and the runtime
both report positions later, and they will only have the tokens to go on.
</details>
