## Core concept

Numbers in the tree, printed the same canonical way the scanner printed them:
`42` prints as `42.0`. The scanner already did the parsing work, so the parser
just carries the value across — a sign that the phase boundary is in the right
place.

## Go APIs

- The literal value already attached to the token.
