## Core concept

`for` adds no runtime machinery: it **desugars** into a block containing an
initializer and a `while`. Building the tree that way means the evaluator never
learns about `for` at all — one of the cheapest ways to add a language feature,
and the reason `for` and `while` cannot disagree about scoping.

```
for (var i = 0; i < 3; i = i + 1) body;
→ { var i = 0; while (i < 3) { body; i = i + 1; } }
```

## Go APIs

- Parser-side construction of `BlockStmt` + `WhileStmt` — no new node types.

## Hints

<details><summary>Nudge</summary>

All three clauses are optional. A missing condition is `true`.
</details>

<details><summary>Approach</summary>

The increment goes *after* the body inside the while's body, so `continue`-like
control flow would still run it. Lox has no `continue`, but the placement is
what makes the desugaring faithful.
</details>
