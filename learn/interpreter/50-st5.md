## Core concept

An optional else-branch, and with it a classic ambiguity: in
`if (a) if (b) x; else y;` which `if` owns the `else`? The grammar is ambiguous;
recursive descent resolves it by construction, because the innermost `if` is
the one still parsing when `else` appears. It binds to the nearest `if`, which
is what every C-family language does.

## Go APIs

- A nullable else-branch on `IfStmt`.
