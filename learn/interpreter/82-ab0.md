## What this stage teaches

Two different failures with two different phases. `class A < A` is a **static**
error — the resolver can see a class inheriting from itself in the source
alone. `class A < someVariable` where the variable holds a string is a
**runtime** error, because only evaluation knows what that name holds.

## Go you'll reach for

- A name comparison in the resolver; a type assertion at declaration time.

## Hints

<details><summary>Nudge</summary>

`A class can't inherit from itself.` and `Superclass must be a class.`
</details>

<details><summary>Approach</summary>

Self-inheritance is visible in the source, so the resolver catches it; a
non-class superclass is only knowable at runtime.
</details>
