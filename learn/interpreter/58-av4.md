## What this stage teaches

`clock()` is a function the interpreter provides rather than one Lox defines,
and it forces the design decision that carries the rest of the course: calling
is expressed through a **`LoxCallable` interface**, so user functions, native
functions and later classes are all "things you can call" without the evaluator
knowing which is which.

## Go you'll reach for

- A `CallExpr` node and a `call()` precedence level above `primary()`.
- A `LoxCallable` interface with `Arity()` and `Call(args)`.
- `clock` defined in the global environment at startup.

## Hints

<details><summary>Nudge</summary>

`clock()` returns seconds since the epoch as a number.
</details>

<details><summary>Approach</summary>

Define natives in the *global* environment, not the current one — they must
stay reachable from inside any scope.
</details>
