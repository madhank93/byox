## What this stage teaches

`return` outside any function is a static error, and catching it means the
resolver has to track **where it is** — inside a function or not. That context
variable grows later to distinguish methods and initializers, which is how
`this` and `super` get checked too.

## Go you'll reach for

- A `currentFunction` enum on the resolver, saved and restored around each
  function body.

## Hints
