## What this stage teaches

The first recursive rule: a parenthesised expression parses by calling back
into the top of the expression grammar, then expecting a `)`. That call is what
makes the parser handle arbitrary nesting without any depth limit written
anywhere.

Grouping survives into the tree as its own node — printed `(group ...)` —
because dropping it would change how a later evaluator sees precedence.

## Go you'll reach for

- A `GroupingExpr` wrapping an inner `Expr`.
- A `consume(type, message)` helper for the closing paren.
