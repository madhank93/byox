## Core concept

`==` differs from every other binary operator: it accepts **any** two values
and never errors. Different types are simply not equal, so `1 == "1"` is
`false` rather than a type error — comparing is always a legitimate question,
even when the answer is obviously no.

## Go APIs

- An `isEqual(a, b interface{}) bool` helper; Go's `==` on `interface{}`
  already compares type and value.

## Hints

<details><summary>Nudge</summary>

`nil == nil` is `true`; `nil == false` is `false`.
</details>

<details><summary>Approach</summary>

`!=` is the negation of the same helper — don't write it twice.
</details>
