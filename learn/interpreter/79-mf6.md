## What this stage teaches

`class B < A` names a superclass, and the superclass is an **expression
evaluated at declaration time**, not a name resolved later. So `A` must already
exist, and the class object holds a pointer to the actual `LoxClass` rather
than to its name.

## Go you'll reach for

- A `Superclass *VariableExpr` on `ClassStmt`, resolved to a `*LoxClass`.

## Hints

<details><summary>Nudge</summary>

Inheriting from something that is not a class is an error — that is stage 82.
</details>

<details><summary>Approach</summary>

Evaluate the superclass expression when the class is declared and store the
resulting class object, not its name.
</details>
