## What this stage teaches

Reading a name that was never declared is a **runtime** error, not a syntax
error — the parser cannot know what will be defined by the time the code runs.
`Undefined variable 'x'.` and exit 70.

Lox reports this at use time rather than returning nil, which is a deliberate
choice: silently producing nil turns a typo into a mystery three lines later.

## Go you'll reach for

- An error return from `Environment.Get` when the key is absent.

## Hints

<details><summary>Nudge</summary>

A declared-but-uninitialised variable holds `nil` and is *not* an error to read.
</details>
