## What this stage teaches

`==` and `!=`, the loosest binary level — so `a < b == c < d` compares the two
comparisons, which is exactly how it reads. With this the expression grammar is
complete: equality → comparison → term → factor → unary → primary.

```
the expression grammar, loosest at the top:

   expression
       |
   equality      ==  !=        <- each level calls the next TIGHTER one,
       |                          so precedence is enforced by call order
   comparison    <  <=  >  >=     alone -- no precedence table anywhere
       |
   term          +  -
       |
   factor        *  /
       |
   unary         -  !           <- recurses into ITSELF: right associative
       |
   primary       literals, (grouping)

   a loop at a level  -> left associative   1-2-3 = (1-2)-3
   recursion into self -> right associative  !!x  = !(!x)
```

## Go you'll reach for

- `equality()`: a `comparison()`, then a loop over `==` and `!=`.

## Hints

<details><summary>Nudge</summary>

`expression()` now calls `equality()`, the outermost level.
</details>

<details><summary>Approach</summary>

Six functions, each one line of grammar. Read them top to bottom and you have

</details>
