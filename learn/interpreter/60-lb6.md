## What this stage teaches

Parameters are just variables defined in the call's environment before the body
runs. Arguments are evaluated **at the call site**, left to right, and their
values bound to the parameter names — call by value, so reassigning a parameter
inside the function cannot affect the caller's variable.

## Go you'll reach for

- A parameter list on `FunctionStmt`; `Define` per parameter in `Call`.

## Hints

<details><summary>Nudge</summary>

Bind by position: the first argument to the first parameter.
</details>

<details><summary>Approach</summary>

Evaluate the arguments at the call site, left to right, then define each
parameter in the call's environment before running the body.
</details>
