## What this stage teaches

The rest of Lox's single-character punctuation: `,` `.` `-` `+` `;` `*`. Worth
noticing what is *not* here — `/` waits until comments arrive, because a slash
might start one, and that lookahead is a different kind of decision.

## Go you'll reach for

- More `switch` cases, one per character.

## Hints

<details><summary>Nudge</summary>

`COMMA` `DOT` `MINUS` `PLUS` `SEMICOLON` `STAR`, each with a `null` literal.
</details>

<details><summary>Approach</summary>

Add them as cases in the same switch. If a new token needs changes anywhere
else, the scanner's structure is fighting you.
</details>
