## Core concept

A new error category with its own exit code: **70** for runtime errors, as
opposed to 65 for malformed source. The distinction matters — a syntax error
means the program was never valid, a runtime error means it was valid and
something went wrong while running it.

`-"muffin"` is the first: negation demands a number.

## Go APIs

- A `RuntimeError` type carrying a message and a line.
- `Operand must be a number.` plus `[line N]` on stderr.

## Hints

<details><summary>Nudge</summary>

The message format is `Operand must be a number.` then a newline and
`[line N]`.
</details>

<details><summary>Approach</summary>

Return errors up the evaluator rather than panicking — the interpreter needs to
print, exit cleanly, and later keep running after a caught error.
</details>
