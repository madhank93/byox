## What this stage teaches

`this` is not magic — it is a **variable**, bound in an environment that wraps
the method's closure when the method is looked up on an instance. Binding at
lookup time rather than call time is what makes a method reference keep its
receiver:

```
var m = instance.method;   // already bound to instance
m();                       // still sees the right `this`
```

## Go you'll reach for

- A `bind(instance)` on `LoxFunction` returning a copy whose closure defines
  `this`.
- A `ThisExpr` the resolver treats as an ordinary local variable.

## Hints

<details><summary>Nudge</summary>

Bind when the property is read, not when the call happens.
</details>

<details><summary>Approach</summary>

Bind when the property is read, not when the call happens, so a detached
method reference keeps its receiver.
</details>
