## Core concept

At the top level, a second `var a` **replaces** the first rather than erroring.
Lox allows this deliberately: the REPL would be miserable otherwise, since you
could never redefine something you just typed. Inside a local scope the rules
tighten again, at stage 69.

## Go APIs

- A plain map assignment in `Define` — no existence check.

## Hints

<details><summary>Nudge</summary>

`var a = 1; var a = 2; print a;` prints `2`.
</details>
