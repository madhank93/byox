## Core concept

`-x` needs a number; `!x` needs Lox's **truthiness** rule, which is narrower
than most languages': only `nil` and `false` are falsey. `0` is true. `""` is
true. Getting this wrong produces a language that looks like Lox and behaves
like JavaScript.

## Go APIs

- An `isTruthy(v interface{}) bool` helper.
- A type assertion to `float64` for negation.

## Hints

<details><summary>Nudge</summary>

`!nil` is `true`, `!0` is `false`, `!!true` is `true`.
</details>

<details><summary>Approach</summary>

Write `isTruthy` once — `if`, `while`, `and` and `or` all use it later.
</details>
