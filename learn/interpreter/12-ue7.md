## Core concept

The first token with a **literal value** distinct from its lexeme: the lexeme
includes the quotes, the value does not. That distinction is why the token
struct has both fields.

It is also the first token that can be unterminated — a string running off the
end of the file is an error the scanner has to detect rather than crash on.

## Go APIs

- A loop advancing until the closing `"` or the end of the source.
- `[line N] Error: Unterminated string.` on stderr.

## Hints

<details><summary>Nudge</summary>

Lox strings can span newlines, so keep counting lines inside the loop.
</details>

<details><summary>Approach</summary>

Lox has no escape sequences — a backslash inside a string is just a backslash,
which makes this simpler than most languages.
</details>

<details><summary>Implementation</summary>

The lexeme includes the quotes, the literal does not — they are different
fields on the token for exactly this reason.
</details>
