## Core concept

Asking for the info dictionary: an extension message using the peer's
`ut_metadata` id, carrying `{"msg_type": 0, "piece": 0}`. Metadata is itself
chunked into 16 KiB pieces — the same block size as file data, reused rather
than reinvented.

## Go APIs

- A bencoded request wrapped in the extension message frame.

## Hints

<details><summary>Nudge</summary>

`msg_type` 0 is request, 1 is data, 2 is reject.
</details>
