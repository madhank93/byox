## What this stage teaches

`l...e` holds any number of values of any type, including other lists — so the
decoder becomes recursive, and each element's decoder must report its own
length so the loop knows where the next one starts. That "return value and
bytes consumed" contract is the whole design.

## Go you'll reach for

- A `decode(data []byte) (value any, n int, err error)` dispatching on the
  first byte.
