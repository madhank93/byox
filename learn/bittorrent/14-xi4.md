## What this stage teaches

Extensions negotiate their own message ids. You send message id 20 with a
bencoded payload `{"m": {"ut_metadata": <n>}}`, where `n` is the id **you** want
the peer to use when sending you metadata messages. Each side picks numbers for
its own inbox, so no central registry is needed.

## Go you'll reach for

- Your bencode encoder; a message with id 20 and sub-id 0.

## Hints

<details><summary>Nudge</summary>

Sub-message id 0 marks the extension handshake itself.
</details>
