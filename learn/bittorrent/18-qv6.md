## What this stage teaches

With the metadata fetched, a magnet download is an ordinary download: you now
hold the same piece length, file length and piece hashes the `.torrent` would
have given you, so the stage-10 routine runs unchanged.

The two paths have converged, and that is the design — magnet links change only
how you *obtain* the metainfo, never what you do with it.

## Go you'll reach for

- The stage 10 piece downloader, on the already-open connection.

## Hints

<details><summary>Nudge</summary>

Keep the connection: you handshook, negotiated extensions and fetched metadata
on it, and it is still good for data.
</details>

<details><summary>Approach</summary>

Reuse the connection you already handshook and negotiated extensions on —
it is a normal peer connection now.
</details>
<details><summary>The API</summary>

The metadata you fetched contains the piece length and piece hashes, so the
stage-10 code runs unchanged.
</details>
