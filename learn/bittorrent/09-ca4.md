## What this stage teaches

68 bytes, fixed: `\x13`, the string `BitTorrent protocol`, 8 reserved bytes, the
20-byte info hash, and your 20-byte peer id. The length prefix on the protocol
name exists so the format could have changed; it never did, so `\x13` is
effectively a magic byte.

The reserved bytes are not dead space — stage 13 sets a bit in them to advertise
extensions.

```
the handshake -- 68 bytes, always:

 +----+---------------------+----------+--------------+--------------+
 | 19 | "BitTorrent protocol"| reserved |  info hash   |   peer id    |
 | 1B |        19 B          |   8 B    |    20 B      |    20 B      |
 +----+---------------------+----------+--------------+--------------+
                                 ^
                                 all zero for now; stage 13 sets
                                 reserved[5] |= 0x10 to say "I speak
                                 the extension protocol"
```

## Go you'll reach for

- `net.Dial("tcp", peer)`, one write, then `io.ReadFull` of 68 bytes.

## Hints

<details><summary>Nudge</summary>

The peer's id is the last 20 bytes of its reply.
</details>

<details><summary>Approach</summary>

Check the returned info hash matches yours — a peer serving a different torrent
should be dropped.
</details>
