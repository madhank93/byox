## Core concept

`info.pieces` is one long byte string: every piece's SHA-1, 20 bytes each,
concatenated with no delimiter. Split it by **length**, not by any separator —
there isn't one, and a hash can contain any byte including whatever you might
have split on.

These hashes are the trust model: peers are strangers, so every piece is
verified before it is kept.

## Go APIs

- A loop slicing `pieces[i*20 : (i+1)*20]`.

## Hints

<details><summary>Nudge</summary>

The count is `len(pieces) / 20`, and it should match the file size divided by
the piece length, rounded up.
</details>
