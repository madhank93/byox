## Core concept

Domain names on the wire have **no dots**. `codecrafters.io` is a sequence of
length-prefixed labels terminated by a zero byte:

```
\x0ccodecrafters\x02io\x00
```

A label length is one byte, so labels max out at 63 characters — and that limit
is not arbitrary: the top two bits are reserved, which stage 7 turns into
compression pointers.

```
"codecrafters.io" on the wire — no dots anywhere:

+----+---------------------------+----+------+------+
| 12 | c o d e c r a f t e r s   | 02 | i o  | 0x00 |
+----+---------------------------+----+------+------+
  ^    ^                           ^     ^      ^
  |    12 bytes of label            |     |      end of name
  length byte                       |     2 bytes of label
                                    length byte
```

## Go APIs

- `strings.Split(name, ".")`, then a length byte per label.
- `TYPE` and `CLASS` as 16-bit values (1 and 1 for A/IN).

## Hints

<details><summary>Nudge</summary>

Don't forget the terminating zero byte after the last label.
</details>

<details><summary>Approach</summary>

Write a length byte per label and a terminating zero. There is no dot in the
encoding at any point.
</details>
