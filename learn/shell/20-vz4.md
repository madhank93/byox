## What this stage teaches

`2>` redirects the error stream, and the number is the file descriptor: 0 is
stdin, 1 stdout, 2 stderr. Keeping them separate is what lets you capture a
command's output while still seeing its errors — the reason shells expose the
numbers at all.

## Go you'll reach for

- The same extraction, keyed on `2>`, assigned to `cmd.Stderr`.

## Hints

<details><summary>Nudge</summary>

`ls nonexistent 2> err.txt` writes the error to the file and nothing to the
terminal.
</details>

<details><summary>Approach</summary>

Both redirections can appear on one command line, so parse them independently.
</details>
