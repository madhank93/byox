## What this stage teaches

`declare` introduces shell variables — values the shell keeps for itself,
distinct from the environment it passes to children. Recognising it as a
builtin is this stage's whole job, and it has to be one for the usual reason:
setting a variable in a child process would help nobody.

## Go you'll reach for

- A `declare` entry in the builtin set.
