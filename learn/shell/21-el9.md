## What this stage teaches

`>>` differs from `>` by one open flag: `O_APPEND` instead of `O_TRUNC`. The
parsing is the same, the plumbing is the same — the semantics live entirely in
how the file is opened, which is a good reminder that "append" is an operating
system behaviour, not a shell one.

## Go you'll reach for

- `os.O_CREATE|os.O_WRONLY|os.O_APPEND`.

## Hints

<details><summary>Nudge</summary>

Appending to a file that does not exist creates it.
</details>
