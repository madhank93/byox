## Core concept

`2>>` — the last combination of the two axes: which descriptor, and truncate or
append. Four operators, two independent choices. If your parser handles the
descriptor and the mode separately, this stage is already done; if it has four
special cases, they will disagree eventually.

## Go APIs

- The same extraction with the append flag.
