## Core concept

An arrow key is not one byte — it is the escape sequence `ESC [ A`, three bytes
the shell must recognise in raw mode. And recalling a line means **redrawing**:
erase what is on screen with backspace-space-backspace for each character, then
print the recalled text, because the terminal has no notion of "replace the
line".

## Go APIs

- A `case 27:` reading two more bytes.
- A history position cursor, and `\b \b` per character to erase.

## Hints

<details><summary>Nudge</summary>

Erase by the length of the *current* buffer, before replacing it.
</details>

<details><summary>Approach</summary>

The position starts past the end of history, so the first up-arrow lands on the
most recent entry.
</details>
