## Core concept

The listing format: `[1]+  Running    sleep 5 &`. The `+` marks the **current**
job — the most recent one — and a `-` marks the one before it. Those markers
exist because `fg` and `bg` default to the current job, so the shell has to
show which that is.

## Go APIs

- `fmt.Printf` with padding; index comparisons for the markers.

## Hints

<details><summary>Nudge</summary>

The command text is what the user typed, `&` included.
</details>

<details><summary>Approach</summary>

The `+` marks the most recent job and `-` the one before it, because `fg`
and `bg` default to the current one.
</details>
