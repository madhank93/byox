## Core concept

Double quotes are the *weaker* quote: they group like single quotes but leave
some characters special. In a full shell that is `$`, backticks and `\`; here it
is enough that a backslash keeps meaning something inside them, which the next
stages pin down.

## Go APIs

- A second state flag, `inDouble`.

## Hints

<details><summary>Nudge</summary>

A single quote inside double quotes is a literal character, and vice versa.
</details>

<details><summary>Approach</summary>

Add a second state flag rather than a second scanner. A single quote inside
double quotes is an ordinary character, and vice versa.
</details>
