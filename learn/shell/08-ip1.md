## Core concept

Running an external command: resolve it on `PATH`, start it, wait for it. Two
details are easy to miss and both are visible to the child. **`argv[0]` is the
name the program was invoked as**, not the resolved path — some programs change
behaviour based on it. And the child inherits the shell's stdin, stdout and
stderr, which is why its output appears without you forwarding anything.

## Go APIs

- `exec.Command(path, args...)`, then `cmd.Args[0] = name`.
- `cmd.Stdout = os.Stdout`, likewise stderr and stdin.
- `cmd.Run()` — start and wait.
