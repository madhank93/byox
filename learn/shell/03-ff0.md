## Core concept

The loop that makes it a shell: prompt, read, evaluate, repeat. And the exit
condition — a read error means stdin closed (Ctrl-D or a pipe running dry), and
the shell should end rather than spin.

## Go APIs

- `for { ... }` around the prompt-and-read.
- An error check on `ReadString` breaking the loop.

## Hints

<details><summary>Nudge</summary>

Print a fresh prompt after every command, including invalid ones.
</details>

<details><summary>Approach</summary>

An empty line should reprompt, not error.
</details>
