## Core concept

The other half of `HISTFILE`: write it back on exit, so the session persists
without the user running anything. The catch is that "exit" has more than one
path — the `exit` builtin and end-of-input both need to go through the same
shutdown, or history is lost whenever the user presses Ctrl-D.

## Go APIs

- One `exitShell()` used by both paths.

## Hints

<details><summary>Nudge</summary>

Write before `os.Exit` — deferred functions do not run after it.
</details>
