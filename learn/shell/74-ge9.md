## What this stage teaches

`$NAME` is replaced with the variable's value **before** the command runs — and
where that happens in the pipeline matters. Expansion comes after quote
handling, so `'$HOME'` stays literal while `"$HOME"` expands, and the command
itself never sees a dollar sign.

## Go you'll reach for

- A pass over each token replacing `$NAME` with its value.

## Hints

<details><summary>Nudge</summary>

The name runs to the first character that cannot be part of an identifier.
</details>

<details><summary>Approach</summary>

Expand after tokenizing but before dispatch, and skip single-quoted text.
</details>
