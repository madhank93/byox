## Core concept

`complete -C prog cmd` registers an **external program** as the completer for a
command. This is the extensibility hook: the shell stops deciding what the
candidates are and delegates to something the user supplied — the mechanism
behind every `git`, `docker` or `kubectl` completion you have ever used.

## Go APIs

- A `map[string]string` from command name to completer path.
