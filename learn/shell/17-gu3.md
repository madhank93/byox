## What this stage teaches

The third and fiddliest rule: inside double quotes a backslash escapes **only**
`$`, `` ` ``, `"`, `\` and newline. Before anything else it stays literal, so
`"\n"` is a backslash and an n, while `"\\"` is one backslash. This selectivity
is why double-quoted strings can contain most punctuation untouched but still
let you write a literal quote.

## Go you'll reach for

- A membership check on the next character inside the double-quote state.

## Hints

<details><summary>Nudge</summary>

`"hello\"insidequotes"` contains a real quote character.
</details>

<details><summary>Approach</summary>

Three contexts, three rules: escape anything, escape nothing, escape five
things. Keeping them as three branches of one state machine beats special cases
scattered around.
</details>
