## What this stage teaches

`complete -p` prints a registered spec back in the form that would recreate it:
`complete -C '<path>' <cmd>`. Printing configuration as the command that
produces it is a small, good habit — it makes the output usable as input.

## Go you'll reach for

- `fmt.Printf("complete -C '%s' %s\n", path, name)`.

## Hints

<details><summary>Nudge</summary>

The completer path is single-quoted; the command name is not.
</details>
