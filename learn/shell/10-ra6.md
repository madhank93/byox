## What this stage teaches

`cd` changes the shell's own working directory — the clearest example of why
builtins exist. Run `cd` as a child process and it would change *that* process's
directory and then exit, leaving the shell exactly where it was.

## Go you'll reach for

- `os.Chdir(path)`.
- `cd: <path>: No such file or directory` on failure.

## Hints

<details><summary>Nudge</summary>

A failed `cd` prints the message and leaves the shell where it was.
</details>
