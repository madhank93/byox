## Core concept

`complete -r cmd` removes a spec, and completion falls back to the default
behaviour. Every registry needs a way out, and the test that it worked is that
the fallback path still functions — not merely that the entry is gone.

## Go APIs

- `delete(completers, name)`.

## Hints

<details><summary>Nudge</summary>

After removal, the command completes files again.
</details>
