## Core concept

`./dir`, `../dir` and bare `dir` are resolved **relative to the current working
directory** — and the resolution happens in the kernel, not in your shell.
`chdir` takes any path and interprets it against the process's current
directory, so relative paths need no special handling.

## Go APIs

- The same `os.Chdir`.
