## What this stage teaches

Inside single quotes a backslash is **just a backslash**. There is no escape
character at all, which is why single quotes are the way to write a literal
string containing anything except a single quote — and why you cannot escape a
single quote inside single quotes.

## Go you'll reach for

- Nothing, if the single-quote state already copies characters verbatim.

## Hints

<details><summary>Nudge</summary>

`'shell\nscript'` prints exactly `shell\nscript`.
</details>

<details><summary>Approach</summary>

If the single-quote state copies bytes verbatim, this stage is already done.
Backslash has no meaning there at all.
</details>
