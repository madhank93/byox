## What this stage teaches

Completing a command means scanning every `PATH` directory for executables with
the right prefix. Two things follow: the same name can appear in several
directories and must be offered **once**, and this is a directory scan per
keystroke — real shells cache it for exactly that reason.

## Go you'll reach for

- `os.ReadDir` per PATH entry; a `map[string]bool` to dedupe.

## Hints

<details><summary>Nudge</summary>

Skip directories that cannot be read rather than failing.
</details>
