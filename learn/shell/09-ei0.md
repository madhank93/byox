## Core concept

The working directory is per-process state, and `pwd` reports the **shell's**.
It has to be a builtin for the same reason `cd` does: a child process asked for
its own directory would answer about itself, which is a different question.

## Go APIs

- `os.Getwd()`.

## Hints
