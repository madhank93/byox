## What this stage teaches

`history -r <file>` loads entries from disk and **appends** them to the current
list rather than replacing it. History is cumulative across sessions, and the
file is plain text, one command per line — a format you can edit in any editor,
which is deliberate.

## Go you'll reach for

- `os.ReadFile`, split on newlines, skipping blanks.

## Hints

<details><summary>Nudge</summary>

A missing file is not an error worth reporting here.
</details>

<details><summary>Approach</summary>

Append to the current history rather than replacing it, and move the flushed
mark so loaded entries are not written straight back out.
</details>
