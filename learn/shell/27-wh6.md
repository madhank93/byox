## What this stage teaches

Ambiguity gets a two-step protocol: the first Tab rings the bell, a second Tab
on the same input lists the candidates and redraws the prompt with what the
user had typed. That means the shell has to **remember the previous keystroke**
— a small piece of modal state in the input loop.

## Go you'll reach for

- A `tabArmed` flag plus the input it was armed for, cleared by any other key.

## Hints

<details><summary>Nudge</summary>

Candidates are printed sorted, separated by two spaces.
</details>

<details><summary>Approach</summary>

After listing, reprint `$ ` and the buffer — the user's line must survive.
</details>

<details><summary>The API</summary>

Store both a `tabArmed bool` and the word it was armed for. Any other
keystroke disarms it, or a Tab on a different word would list the previous
word's candidates.
</details>
