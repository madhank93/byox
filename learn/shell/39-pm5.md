## Core concept

Running the registered program and using its **stdout lines** as candidates.
The contract is deliberately plain text — one candidate per line — which is why
a completer can be written in any language.

## Go APIs

- `exec.Command(path, ...).Output()`, split on newlines.

## Hints

<details><summary>Nudge</summary>

A single candidate completes and appends a space, as always.
</details>

<details><summary>Approach</summary>

A completer that fails or prints nothing should be treated as no candidates,
not as an error.
</details>
