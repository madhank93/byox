## Core concept

Shared-prefix completion for filenames. Same helper as stage 28 — and if it
takes a `[]string` rather than reaching for PATH itself, this stage is a call
site rather than an implementation.

## Go APIs

- `longestCommonPrefix` over the file matches.

## Hints

<details><summary>Nudge</summary>

Preserve the directory part of the word when inserting the prefix.
</details>

<details><summary>Approach</summary>

Split the word at the last `/` first: the shared prefix is computed over the
final segment only, and the directory part is prepended back afterwards.
</details>
<details><summary>Implementation</summary>

The same `longestCommonPrefix` helper as stage 28 — pass it the candidate
list and let the caller deal with paths.
</details>
