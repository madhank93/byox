## What this stage teaches

Several matching files list on a second Tab, exactly as several commands did.
The double-tab protocol is a property of the line editor, not of what is being
completed — one implementation, many sources.

## Go you'll reach for

- The shared `tabArmed` listing path.

## Hints

<details><summary>Nudge</summary>

Sort the names; the tester compares the listing exactly.
</details>

<details><summary>Approach</summary>

The listing path is the same one the command completion used — if it is
duplicated, the two will drift on spacing or sorting.
</details>
<details><summary>The API</summary>

Print `\r\n`, the names joined by two spaces, then `\r\n$ ` and the buffer,
so the user's line survives the listing.
</details>
