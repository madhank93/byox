## What this stage teaches

A directory completes with a trailing `/` rather than a space, so the next Tab
can descend into it. That single character is a piece of interface design: it
tells you the match is a directory and leaves you positioned to continue.

## Go you'll reach for

- `entry.IsDir()` deciding the suffix.

## Hints

<details><summary>Nudge</summary>

Files get a trailing space; directories get `/` and no space.
</details>
