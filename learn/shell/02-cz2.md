## What this stage teaches

Reading a line and reporting that the command does not exist. The message
format matters — `<command>: command not found` — and so does where it goes:
this is the first of many places where a shell writes about a command rather
than for it.

## Go you'll reach for

- `bufio.NewReader(os.Stdin)` and `ReadString('\n')`.
- `strings.TrimSpace` to drop the newline.

## Hints

<details><summary>Nudge</summary>

Trim the trailing newline before using the input, or it becomes part of the
command name.
</details>
