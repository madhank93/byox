## What this stage teaches

`type` makes the shell's own lookup rule visible: builtin first, then the
directories of `PATH` in order, first match wins. Implementing it forces you to
write that resolution explicitly rather than leaving it implicit in the
dispatch code — and every later stage reuses it.

## Go you'll reach for

- A set of builtin names.
- `exec.LookPath`, or a manual walk over `PATH`.

## Hints

<details><summary>Nudge</summary>

`type echo` → `echo is a shell builtin`. `type ls` → `ls is /bin/ls`. Neither →
`x: not found`.
</details>
