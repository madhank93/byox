## Core concept

The biggest change in the course: to react to a Tab **as it is typed**, the
shell can no longer read whole lines. It switches the terminal out of canonical
mode, receives every keystroke immediately, and takes over echoing and
backspace handling itself.

The trade is total. You now own the line editor: what the user sees is what you
printed, and forgetting to echo a character makes it invisible though still
present in the buffer.

```
canonical mode (stages 1-22)        raw/cbreak mode (from here)
-----------------------------      ----------------------------
 keystrokes                          keystrokes
     |                                   |
 [ terminal driver ]                     |   (no line buffer,
   buffers the line                      |    no echo)
   echoes it                             |
   handles backspace                     v
     |                              your program
     | (on Enter)                     - echoes each byte itself
     v                                - handles backspace itself
 your program reads a line            - sees Tab the moment it is typed

you gain: reacting to a keystroke mid-line.
you owe:  echo, backspace, redraw -- forget one and the character is
          invisible but still in the buffer.
```

## Go APIs

- `golang.org/x/term` or `unix.IoctlSetTermios` to clear `ICANON` and `ECHO`.
- A byte-at-a-time read loop building the line yourself.
- Restoration of the old terminal state on exit.

## Hints

<details><summary>Nudge</summary>

Tab completes a builtin name and appends a trailing space.
</details>

<details><summary>Approach</summary>

Leave `OPOST`/`ONLCR` alone: full raw mode stops `\n` becoming `\r\n`, and
every line of output after that starts in the wrong column.
</details>
