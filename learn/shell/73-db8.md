## What this stage teaches

A variable name is a letter or underscore followed by letters, digits and
underscores — the same rule nearly every language uses, and for the same reason:
a name that could start with a digit would be ambiguous with a number.

`declare 1abc=1` is rejected with ``declare: `1abc=1': not a valid identifier``,
and note the message quotes the **whole argument**, not just the name.

## Go you'll reach for

- An `isValidIdentifier(name string) bool` over the runes.
