## What this stage teaches

`HISTFILE` makes persistence automatic: if it is set, the shell loads that file
at startup without being asked. Configuration through the environment is the
Unix convention — no config file to parse, and a per-invocation override for
free.

## Go you'll reach for

- `os.Getenv("HISTFILE")` before the REPL starts.

## Hints

<details><summary>Nudge</summary>

Unset `HISTFILE` means no automatic loading at all.
</details>
