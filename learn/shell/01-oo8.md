## What this stage teaches

A shell is a REPL, and the prompt is the "read" half announcing itself. The
detail that bites: a prompt has **no trailing newline**, so whether it appears
depends on flushing. Go's `fmt.Print` to `os.Stdout` is unbuffered and lands
immediately; wrap stdout in a `bufio.Writer` and the prompt sits invisible in
the buffer while the tester waits for it.

## Go you'll reach for

- `fmt.Print("$ ")`.

## Hints

<details><summary>Nudge</summary>

Exactly `"$ "` — dollar, space, nothing else.
</details>

<details><summary>Approach</summary>

If you later add a buffered writer for speed, flush before every read.
</details>
