## What this stage teaches

`${NAME}` braces the name explicitly, which exists to solve one problem:
`$NAMEsuffix` would be read as a variable called `NAMEsuffix`. The braces mark
where the name ends, letting the value be followed immediately by other text.

## Go you'll reach for

- A branch on `${` reading up to the closing `}`.

## Hints

<details><summary>Nudge</summary>

`${a}bc` is the value of `a` followed by `bc`.
</details>
