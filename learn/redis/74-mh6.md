## Core concept

`RPUSH` on a missing key creates the list. Same defaulting rule as `INCR` on a
missing key, applied to a container type: Redis has no `CREATE`, because the
first write to a key defines its type.

The reply is the list's new length, which is what makes `RPUSH` usable as both a
write and a counter.

## Go APIs

- `[]string` stored in the same tagged-value keyspace as strings and streams.
- An integer reply with the new length.

## Hints

<details><summary>Nudge</summary>

`RPUSH key element` on a new key gives `:1\r\n`.
</details>

<details><summary>Approach</summary>

`append` on a nil slice works, so the missing-key case needs no branch at all.
</details>
