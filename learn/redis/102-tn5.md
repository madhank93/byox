## Core concept

A valid coordinate is stored as a sorted-set member. Nothing new is invented —
this is the stage that confirms geo really is sorted sets underneath, since
`ZSCORE` on a `GEOADD`ed member returns the encoded score and `ZRANGE` lists geo
members in score order.

## Go APIs

- The `ZADD` write path, unchanged.

## Hints

<details><summary>Nudge</summary>

The score is computed next stage; storing any placeholder passes this one.
</details>

<details><summary>Approach</summary>

Don't add a parallel geo map. One structure, or `ZSCORE` and `GEOPOS` will
disagree.
</details>
