## What this stage teaches

Redis has users. Every connection is authenticated as someone, and before anyone
logs in that someone is the built-in user named `default` — so `ACL WHOAMI`
always has an answer and there is no unauthenticated state to special-case.

## Go you'll reach for

- A `user` field on the connection, initialised to `"default"`.
- A bulk-string reply.

## Hints

<details><summary>Nudge</summary>

`ACL WHOAMI` before any `AUTH` returns `default`.
</details>

<details><summary>Approach</summary>

Put the current user on the connection now — the enforcement stages read it, and
retrofitting identity is harder than carrying it.
</details>
