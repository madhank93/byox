## What this stage teaches

`LRANGE key start stop` is **inclusive at both ends** — unlike Go's slicing,
unlike most languages' ranges. And out-of-range indexes are not errors: they
clamp. `LRANGE key 0 999` on a three-element list returns three elements, and a
start past the end returns an empty array.

Clamping instead of erroring is deliberate: it lets a client page through a list
without knowing its length.

## Go you'll reach for

- `strconv.Atoi` on both bounds.
- Clamp `stop` to `len(list)-1`, then slice `list[start : stop+1]`.

## Hints

<details><summary>Nudge</summary>

`LRANGE key 0 -1`-style negatives come next stage; positives only here.
</details>

<details><summary>Approach</summary>

Clamp first, then check `start > stop` and return the empty array. Slicing
before clamping panics.
</details>
