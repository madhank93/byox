## What this stage teaches

Only commands that **change state** belong in the log. `GET`, `PING` and
`CONFIG GET` change nothing, so logging them inflates the file and slows every
restart without affecting the replayed state at all. This forces an explicit
classification of your command set — read versus write — which the replication
stages need too.

## Go you'll reach for

- A `map[string]bool` of write commands, or a `switch` returning `isWrite`.

## Hints

<details><summary>Nudge</summary>

At this point in the course the write set is small: `SET` and little else.
</details>

<details><summary>Approach</summary>

Classify by command name in one place and consult it from the AOF path. Stage 34
propagates writes to replicas using the same judgement — one predicate, two
callers.
</details>
