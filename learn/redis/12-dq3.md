## What this stage teaches

Multiple keys *and* their values. If the previous three stages were built as
reusable pieces — a length decoder, a string reader, an opcode loop — this stage
is nearly free, and that is the signal the decomposition was right. If it isn't
free, the fix is factoring rather than more parsing.

## Go you'll reach for

- Nothing new — the same `readLength`, `readString`, opcode switch.

## Hints

<details><summary>Nudge</summary>

`KEYS *` returns every key; each `GET` returns its value. Same loop, no special
cases.
</details>

<details><summary>Approach</summary>

If this stage needs new code, look for a place where you assumed a single pair —
a `break` after the first key, or a variable that should have been a map entry.
</details>
