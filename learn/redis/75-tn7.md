## What this stage teaches

`RPUSH` onto an existing list appends at the tail and returns the new length.
The pairing to keep straight for the rest of the list stages: **R** is the right
(tail) end, **L** is the left (head) end, and every list command carries one of
those letters.

## Go you'll reach for

- `append(list, value)`, then reply with `len(list)`.

## Hints

<details><summary>Nudge</summary>

Order is preserved — the new element is last.
</details>

<details><summary>Approach</summary>

Write the modified slice back into the map. Appending to a local copy of a slice
header is the classic Go mistake that silently loses writes.
</details>
