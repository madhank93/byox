## What this stage teaches

`ZSCORE` returns the score as a **bulk string**, not a RESP double — RESP2 has
no float type, so numbers become text and the formatting is part of the
protocol. Redis prints the shortest representation that round-trips, so `3.0`
comes back as `3`, not `3.0000000000`.

Missing member, or missing key, is a null bulk string.

## Go you'll reach for

- `strconv.FormatFloat(score, 'f', -1, 64)` — precision `-1` picks the shortest
  form that parses back exactly.

## Hints

<details><summary>Nudge</summary>

`fmt.Sprintf("%v", f)` can produce scientific notation for large or small
values. `FormatFloat` with `'f'` never does.
</details>

<details><summary>Approach</summary>

Get this right here and the geo stages inherit it — their scores are 52-bit
integers stored as floats, where `%v` would print `1.234567890123e+15`.
</details>
