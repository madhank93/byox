## What this stage teaches

More members, and the distinction `ZADD`'s return value draws: adding is 1,
updating an existing member's score is 0. The set's size is what the number
describes, not whether anything changed — a client can use it to learn whether
it created something without a second round trip.

## Go you'll reach for

- A presence check before assignment, to decide the reply.

## Hints

<details><summary>Nudge</summary>

Updating a score still stores the new score; only the *count* is 0.
</details>

<details><summary>Approach</summary>

Check membership before writing, since the write erases the evidence.
</details>
