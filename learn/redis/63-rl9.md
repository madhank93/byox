## What this stage teaches

`DISCARD` throws the queue away and leaves the transaction. Every stateful
feature needs an abort path, and the discipline is that abort and commit must
reset *exactly the same fields* — a `DISCARD` that forgets one leaves the
connection in a state no valid sequence could produce.

## Go you'll reach for

- Clear `inMulti`, empty `queued`, reply `+OK\r\n`.

## Hints

<details><summary>Nudge</summary>

`DISCARD` outside `MULTI` is `-ERR DISCARD without MULTI`.
</details>

<details><summary>Approach</summary>

Write one `resetTransaction()` and call it from both `EXEC` and `DISCARD`. Stage
72 and 73 add `WATCH` clearing to it — one place, both paths.
</details>
