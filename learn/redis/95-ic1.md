## What this stage teaches

`ZRANGE key start stop` lists members by rank, inclusive at both ends and
clamping out-of-range bounds — the same rules as `LRANGE`. Recognising that two
different data types share one range convention is the point; if you factored
the bounds logic at stage 77, it applies unchanged here.

## Go you'll reach for

- The sorted member list, sliced with the clamped bounds.

## Hints

<details><summary>Nudge</summary>

Members only, in score order — scores are not included without `WITHSCORES`.
</details>

<details><summary>Approach</summary>

Sort with the comparator from `ZRANK`, then reuse the clamping helper from
`LRANGE`.
</details>
