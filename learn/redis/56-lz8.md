## What this stage teaches

`INCR` on a key that does not exist treats it as 0 and stores 1. Redis does this
throughout — a missing key behaves as the empty value of whatever type the
command needs — which is why counters need no initialisation and `RPUSH` needs
no `CREATE`.

## Go you'll reach for

- A map lookup whose "not found" branch starts from 0.

## Hints

<details><summary>Nudge</summary>

Reply `:1\r\n` and leave the key set to `"1"`.
</details>

<details><summary>Approach</summary>

Fold the missing case into the same path rather than branching: default to 0,
then increment.
</details>
