## What this stage teaches

`LLEN` returns the length, and `LLEN` on a missing key returns 0 rather than an
error — the same "missing key is the empty value of its type" rule as `INCR` and
`RPUSH`. Once you have seen it three times it stops being a special case and
becomes the model.

## Go you'll reach for

- An integer reply with `len(list)`.

## Hints

<details><summary>Nudge</summary>

A nil slice has length 0, so the missing case needs no branch.
</details>
