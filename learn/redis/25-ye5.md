## Core concept

`INFO replication` reports the server's role. The reply shape is worth noting:
not an array, but a **single bulk string** containing newline-separated
`key:value` lines. Redis's introspection commands mostly work this way — human
text inside one protocol value, parsed by clients that care.

## Go APIs

- `strings.Join(lines, "\r\n")` wrapped as one bulk string.

## Hints

<details><summary>Nudge</summary>

`role:master` is the line the tester looks for.
</details>

<details><summary>Approach</summary>

Build the lines in a slice and encode once. The next three stages add fields to
the same reply.
</details>
