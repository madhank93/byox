## Core concept

`XADD key *` takes the current time in milliseconds and picks a sequence. It
brings wall-clock time into an ordering invariant, which is uncomfortable and
correct: two entries within the same millisecond differ only by sequence, so the
sequence must increment rather than reset.

## Go APIs

- `time.Now().UnixMilli()`.
- The stage-45 logic, with the millisecond supplied instead of parsed.

## Hints

<details><summary>Nudge</summary>

`*` is just `<now>-*`. Reuse the previous stage's path.
</details>

<details><summary>Approach</summary>

If the clock reports a millisecond that is not greater than the last entry's,
keep the last entry's millisecond and increment the sequence — never emit a
smaller id.
</details>
