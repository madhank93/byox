## Core concept

`-1` is the last element, `-2` the one before it, and `LRANGE key 0 -1` is the
idiom for "the whole list". Normalising negatives (`if i < 0 { i += len(list) }`)
before any bounds work keeps the rest of the function unchanged — the same
edge-normalisation discipline as `-` and `+` in `XRANGE`.

## Go APIs

- `if i < 0 { i += len(list) }`, then clamp to 0.

## Hints

<details><summary>Nudge</summary>

A negative that is still negative after adding the length clamps to 0, not to an
error.
</details>

<details><summary>Approach</summary>

Normalise both bounds through one small function, then reuse stage 77's clamped
slice untouched.
</details>
