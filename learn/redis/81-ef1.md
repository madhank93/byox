## What this stage teaches

`LPOP` removes and returns the head — a destructive read, where the reply *is*
the removed value and the caller has the only copy. And it raises a housekeeping
question Redis answers firmly: a list that becomes empty is **deleted**, not
kept as an empty list. `EXISTS` and `TYPE` must then report it as missing.

## Go you'll reach for

- `list[0]` for the reply, `list[1:]` for the remainder.
- `delete(store, key)` when the remainder is empty.

## Hints

<details><summary>Nudge</summary>

`LPOP` on a missing or empty list is a null bulk string, `$-1\r\n`.
</details>

<details><summary>Approach</summary>

Delete the key when the list empties, or `TYPE` starts reporting `list` for a
key with nothing in it.
</details>
