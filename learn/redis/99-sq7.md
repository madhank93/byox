## What this stage teaches

`ZREM` removes a member and returns how many were removed — 0 if it wasn't
there. And the same housekeeping rule as lists applies: a sorted set that loses
its last member is deleted, so `TYPE` and `EXISTS` report it as gone.

## Go you'll reach for

- `delete(set, member)`, and `delete(store, key)` when the set empties.

## Hints

<details><summary>Nudge</summary>

Removing a member that isn't there is `:0\r\n`, not an error.
</details>

<details><summary>Approach</summary>

Lists, sorted sets and streams all want this cleanup. One helper called after
any removal keeps it consistent.
</details>
