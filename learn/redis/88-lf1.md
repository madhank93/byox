## What this stage teaches

`PING` is allowed in subscribed mode but answers differently: an array
`["pong", ""]` instead of `+PONG`. The reason is consistency — everything
arriving on a subscribed connection is a multi-element array, so a client can
read messages uniformly without a special case for a status reply.

- A branch in the `PING` case on the subscribed flag.
