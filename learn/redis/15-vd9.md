## What this stage teaches

Configuration has layers: a built-in default, overridden by a command-line flag.
That precedence is the whole stage, and it is the pattern every real server
follows (with a config file usually sitting between the two).

## Go you'll reach for

- `flag.String("appendonly", "no", "")`, `flag.String("appenddirname", "appendonlydir", "")`.
- Or a manual `os.Args` scan if you are already doing that for `--dir`.

## Hints

<details><summary>Nudge</summary>

`CONFIG GET` must report the flag's value when one was passed, the default when
not.
</details>

<details><summary>Approach</summary>

Seed the config map with defaults, then let flag parsing overwrite entries. One
lookup path, no branching in the handler.
</details>
