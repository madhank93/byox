## Core concept

`LPOP key 2` pops two — and changes the reply *type*: with a count it returns an
**array**, without one a **bulk string**. A command whose reply shape depends on
whether an optional argument was supplied is common in Redis and worth noticing,
because "supplied as 1" and "not supplied" are different.

## Go APIs

- `len(args) > 2` to detect the count, not the count's value.
- Clamp the count to the list length.

## Hints

<details><summary>Nudge</summary>

`LPOP key 1` returns a one-element array; `LPOP key` returns a bare bulk string.
</details>

<details><summary>Approach</summary>

Popping more than the list holds returns everything and deletes the key — not an
error.
</details>
