## Core concept

Negative indexes count from the end, exactly as in `LRANGE`. Redis is
consistent about this across every range command, and the practical consequence
is that one normalising helper serves all of them — if this stage needs new
logic, the helper was written in the wrong place.

## Go APIs

- The same normalise-then-clamp helper.

## Hints

<details><summary>Nudge</summary>

`ZRANGE key 0 -1` returns the whole set in score order.
</details>

<details><summary>Approach</summary>

If `LRANGE` and `ZRANGE` have separate bounds code, merge them now — the geo
stages need your attention more than duplicated arithmetic does.
</details>
