## Core concept

A server is a socket bound to a port plus a loop that accepts connections. The
listener itself never carries data — it hands you a separate connection socket
per client. Redis's port is 6379, and using the right one matters here because
the tester connects by port, not by anything you print.

## Go APIs

- `net.Listen("tcp", "0.0.0.0:6379")` — bind, and fail loudly if the port is taken.
- `l.Accept()` — blocks until a client arrives.

## Hints

<details><summary>Nudge</summary>

Nothing is sent or received at this stage. A successful TCP connect is the whole
test.
</details>

<details><summary>Approach</summary>

Bind to `0.0.0.0`, not `localhost`, so the tester reaches you however it
resolves the host. Exit non-zero on a bind failure — "address already in use"
from a previous run you didn't kill is the error you'll see most.
</details>
