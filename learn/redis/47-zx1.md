## What this stage teaches

`XRANGE key start end` returns entries in an **inclusive** range, and its reply
is the most deeply nested structure in the course: an array of entries, each an
array of `[id, [field, value, field, value, …]]`. RESP nests without limit —
this is where that stops being theoretical.

## Go you'll reach for

- A recursive or explicit nested-array encoder.
- A scan over the sorted `[]entry`, or a binary search.

## Hints

<details><summary>Nudge</summary>

Both ends are inclusive. A start id with no sequence part means sequence 0.
</details>

<details><summary>Approach</summary>

Build the encoder to take nested `[]any` (or a small tree type) rather than
hand-assembling the bytes per command. `XREAD` reuses it immediately.
</details>
