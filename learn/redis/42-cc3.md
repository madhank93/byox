## What this stage teaches

`TYPE` forces a decision you have been able to avoid: the keyspace holds more
than strings from here on, so a value needs to carry its own type. One map per
type, or one map of tagged values — either works, but choosing now beats
discovering the need halfway through the stream stages.

`TYPE` on a missing key returns the simple string `none`, not an error and not a
null.

## Go you'll reach for

- A value struct with a `kind` field, or `map[string]any` plus a type switch.
- Simple-string replies: `+string\r\n`, `+stream\r\n`, `+none\r\n`.

## Hints

<details><summary>Nudge</summary>

Three answers matter for the next stages: `string`, `stream`, `none`.
</details>

<details><summary>Approach</summary>

Tagging one entry type scales better than parallel maps — expiry, `WATCH`
versioning and `TYPE` then all read one place instead of N.
</details>
