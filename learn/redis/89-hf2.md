## What this stage teaches

`PUBLISH channel message` returns the number of subscribers it reached. That
return value is the whole delivery guarantee: Redis pub/sub is fire-and-forget,
so the count is the publisher's only feedback, and a count of 0 means the message
is simply gone.

## Go you'll reach for

- A lookup in the server's channel map; integer reply with the subscriber count.

## Hints

<details><summary>Nudge</summary>

The count alone passes this stage — delivery is the next one.
</details>

<details><summary>Approach</summary>

Count under the same lock that guards the map, so a concurrent `SUBSCRIBE`
doesn't produce a count that was never true.
</details>
