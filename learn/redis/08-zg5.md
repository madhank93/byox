## Core concept

`CONFIG GET dir` and `CONFIG GET dbfilename` are the doorway to persistence: the
server has to know where its snapshot lives before it can read one. The reply
shape is the lesson — `CONFIG GET` returns a **flat array** of key, value, key,
value, not a nested map, because RESP2 has no map type.

## Go APIs

- `flag.String("dir", "", "")` and `flag.String("dbfilename", "", "")`.
- An array reply: `*2\r\n$3\r\ndir\r\n$N\r\n<path>\r\n`.

## Hints

<details><summary>Nudge</summary>

The subcommand (`GET`) is `args[1]`, and the parameter name is `args[2]`.
</details>

<details><summary>Approach</summary>

Write a small helper that encodes `[]string` as a RESP array of bulk strings.
`CONFIG GET`, `KEYS`, `XRANGE` and half the later stages all need it.
</details>
