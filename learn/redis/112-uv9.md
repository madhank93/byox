## What this stage teaches

`--requirepass <password>` sets the default user's password, and the transition
matters: setting a password **removes** the `nopass` flag and adds the hash to
`passwords`. The two are mutually exclusive states of one user, not independent
settings — a user with both would be a contradiction the server has to resolve
somehow, so it never allows it.

## Go you'll reach for

- The flag, hashed at startup.
- Clearing `nopass` when a password is present.

## Hints

<details><summary>Nudge</summary>

`ACL GETUSER default` should now show an empty `flags` and one entry in
`passwords`.
</details>

<details><summary>Approach</summary>

Derive the flags from the user's state when building the reply, rather than
maintaining a flags list alongside it. Then the two cannot disagree.
</details>
