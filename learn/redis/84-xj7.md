## Core concept

`BLPOP key 0.1` — and note the timeout is in **seconds, as a float**, unlike
`XREAD BLOCK`'s integer milliseconds. Two blocking commands, two different time
units, in one protocol. Timing out returns a null array (`*-1\r\n`).

## Go APIs

- `strconv.ParseFloat`, then `time.Duration(secs * float64(time.Second))`.

## Hints

<details><summary>Nudge</summary>

`0` still means block forever, as it did for `XREAD`.
</details>

<details><summary>Approach</summary>

Convert to a `time.Duration` at parse time so the wait loop never juggles units.
</details>
