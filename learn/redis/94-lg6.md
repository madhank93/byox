## What this stage teaches

`ZRANK` gives a member's 0-based position in score order — and this is where the
tie-break rule stops being trivia. Equal scores are ordered
**lexicographically by member**, so ranks are stable and two clients asking the
same question get the same answer.

A member that isn't in the set gets a null bulk string, not `-1` and not an
error.

## Go you'll reach for

- `sort.Slice` with a comparator: score first, member name second.
- `strings.Compare` or plain `<` on the member for the tie.

## Hints

<details><summary>Nudge</summary>

The lowest score is rank 0.
</details>

<details><summary>Approach</summary>

Write the comparator once and use it for `ZRANK`, `ZRANGE` and `ZREMRANGE`-style
lookups. Two comparators that disagree produce ranks that don't match the listing.
</details>
