## Core concept

`ZCARD` returns the number of members, 0 for a missing key. "Cardinality" is the
set-theory word, and Redis uses it consistently — `SCARD`, `ZCARD`, `HLEN` — so
the naming itself tells you a command counts a collection.

## Go APIs

- An integer reply with the map's length.
