## Core concept

`PSYNC ? -1` asks for a full resynchronisation: `?` means "I don't know your
replication id" and `-1` means "I have no offset". A replica that *did* know
both would send them and might get a cheap partial resync instead — the same
command covers both cases, which is why the arguments look odd.

The master answers `+FULLRESYNC <replid> <offset>\r\n`, and those two values are
what the replica adopts as its starting state.

```
the full handshake, replica on the left:

  replica                                     master
     |                                          |
     |  PING                                    |
     |----------------------------------------->|
     |                                   +PONG  |
     |<-----------------------------------------|
     |  REPLCONF listening-port <port>          |
     |----------------------------------------->|
     |                                     +OK  |
     |<-----------------------------------------|
     |  REPLCONF capa psync2                    |
     |----------------------------------------->|
     |                                     +OK  |
     |<-----------------------------------------|
     |  PSYNC ? -1        "no id, no offset"    |
     |----------------------------------------->|
     |            +FULLRESYNC <replid> 0        |
     |<-----------------------------------------|
     |            $<len>\r\n<rdb bytes>          |  <- no trailing CRLF
     |<-----------------------------------------|
     |                                          |
     |     ... then the command stream, forever |
     |<-----------------------------------------|
```

## Go APIs

- One more encoded command, then read the `+FULLRESYNC` line.
- `strings.Fields` to pull the id and offset out of it.

## Hints

<details><summary>Nudge</summary>

Sending it is enough to pass; parsing the reply is what the next stages need.
</details>

<details><summary>Approach</summary>

Store the returned offset — the replica's own offset counter starts from it, and
stage 37's ACKs are measured against it.
</details>
