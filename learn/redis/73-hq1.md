## What this stage teaches

`DISCARD` clears watches too. Taken with the previous stage the rule is simple:
every exit from a transaction returns the connection to a clean baseline. The
stage exists because it is exactly the kind of symmetry that gets missed —
commit paths get the attention, abort paths get written once and forgotten.

## Go you'll reach for

- The same shared reset.

## Hints

<details><summary>Nudge</summary>

`MULTI` … `DISCARD` … `WATCH` … `EXEC` must see only the *new* watch.
</details>

<details><summary>Approach</summary>

Three exits now share one reset: `EXEC` committed, `EXEC` abandoned, `DISCARD`.
Route all three through it.
</details>
