## Core concept

`WATCH k1 k2 k3`, and any one of them changing is enough to abandon the
transaction. Conflict detection is a disjunction, not a conjunction — the
transaction assumed *all* the watched keys were stable, so a single violation
invalidates the assumption.

## Go APIs

- A loop over every argument in `WATCH`, and over the whole watch set in `EXEC`.

## Hints

<details><summary>Nudge</summary>

One `WATCH` can name several keys; several `WATCH` calls accumulate.
</details>

<details><summary>Approach</summary>

Return from the comparison loop on the first mismatch. There is nothing to gain
from checking the rest.
</details>
