## What this stage teaches

`XADD key 5-*` means "this millisecond, next sequence number". The rule has one
edge worth internalising: if the stream already holds entries at that
millisecond, the sequence is last+1; if not, it starts at 0 — except at
millisecond 0, where it starts at 1, because `0-0` is forbidden.

## Go you'll reach for

- `strings.HasSuffix(id, "-*")` and a split on `-`.
- The stream's last entry to derive the sequence.

## Hints

<details><summary>Nudge</summary>

Three cases: same millisecond as the last entry, a new millisecond, and
millisecond 0.
</details>

<details><summary>Approach</summary>

Resolve the id to concrete numbers *before* validating it, so auto-generated and
explicit ids run through the same checks.
</details>
