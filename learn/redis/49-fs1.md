## Core concept

The mirror of `-`: `+` is the largest possible id. If stage 48 was written as a
normalising parser, this is a one-line addition — and that is the check. A stage
that should be trivial and isn't points at logic living in the wrong place.

## Go APIs

- The same `parseRangeID`, mapping `+` to the maximum.

## Hints

<details><summary>Nudge</summary>

`XRANGE key - +` returns the whole stream.
</details>

<details><summary>Approach</summary>

Use `math.MaxUint64` for both parts rather than the stream's current last id —
the bound should not shift as entries are added mid-scan.
</details>
