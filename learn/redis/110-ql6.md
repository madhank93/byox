## What this stage teaches

`nopass` is a flag on the default user meaning "any password is accepted" —
which is how a fresh Redis is open to anyone who can reach the port. It is the
setting behind years of internet-exposed Redis incidents, and seeing it as an
explicit, inspectable flag rather than an absence of configuration is the point.

## Go you'll reach for

- A `flags` array in the `ACL GETUSER` reply, containing `nopass`.

## Hints

<details><summary>Nudge</summary>

`flags` is a nested array of bulk strings, even with one element.
</details>

<details><summary>Approach</summary>

Model it as a real field on the user, not a hardcoded string in the reply — the
next stages remove it when a password is set.
</details>
