## Core concept

`MULTI` then `EXEC` with nothing between returns an empty array, `*0\r\n` — not
a null array, not `+OK`. The distinction between "no elements" and "no value" is
one RESP is careful about, and clients rely on it.

## Go APIs

- `*0\r\n`, and a reset of the transaction state.

## Hints

<details><summary>Nudge</summary>

`*0\r\n` is an empty array; `*-1\r\n` is a null array. Different things.
</details>

<details><summary>Approach</summary>

Clear `inMulti` and the queue on `EXEC` whether or not anything ran, so the
connection returns to normal in every path.
</details>

<details><summary>Implementation</summary>

`*0\r\n` is an empty array; `*-1\r\n` is a null array. Stage 68 needs the
second one, so keep them distinct now.
</details>
