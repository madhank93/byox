## Core concept

`GEOPOS key m1 m2` returns one element per member: either a two-element array of
longitude and latitude as bulk strings, or a **null array** for a member that
isn't in the set. Nulls inside an array — rather than a shorter array — is how
RESP keeps positional replies aligned with the request.

## Go APIs

- The nested-array encoder, with `*-1\r\n` for missing members.

## Hints

<details><summary>Nudge</summary>

Longitude first, matching `GEOADD`.
</details>

<details><summary>Approach</summary>

The reply's length always equals the number of members asked for. Skipping
missing ones misaligns every element after it.
</details>
