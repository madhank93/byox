## What this stage teaches

Watching a key that does not exist must still detect its **creation**. Absence
is a state like any other, and "the key wasn't there when I looked" is exactly
the assumption a transaction might depend on — think of a lock implemented as
"set this key if nobody else has".

## Go you'll reach for

- Version 0 for a key that has never existed, incremented on creation.

## Hints

<details><summary>Nudge</summary>

If a version map starts every unknown key at 0, creation bumping it to 1 is
detected with no special case.
</details>

<details><summary>Approach</summary>

Bump the version on deletion too — a key that disappears and reappears has
changed twice, and a watcher should see that.
</details>
