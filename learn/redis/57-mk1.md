## What this stage teaches

`INCR` on a key holding `"foo"` is an error:
`-ERR value is not an integer or out of range`. Redis is dynamically typed but
not permissive — the command validates at execution time and refuses. That
distinction matters at stage 64, where a queued command failing *inside* a
transaction still does not abort the transaction.

## Go you'll reach for

- The error from `strconv.Atoi`, turned into that exact reply.

## Hints

<details><summary>Nudge</summary>

The key keeps its original value. A failed `INCR` changes nothing.
</details>

<details><summary>Approach</summary>

Match the message exactly, including "or out of range" — the tester compares the
whole string.
</details>
