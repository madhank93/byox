## What this stage teaches

The last stage closes the loop: authenticate, then run commands normally. Two
properties get checked at once — that a correct password lifts the gate, and
that it lifts it **for that connection only**. Authentication is per-connection
state, like transactions and subscriptions before it, and a global
`authenticated` flag would let one client's login open the door for everybody.

## Go you'll reach for

- The connection's `authenticated` flag, set by `AUTH` and read by the gate.

## Hints

<details><summary>Nudge</summary>

After a successful `AUTH`, `ACL WHOAMI` reports the authenticated user.
</details>

<details><summary>Approach</summary>

Open two connections, authenticate one, and confirm the other is still refused.
That is the property this stage exists to check.
</details>
