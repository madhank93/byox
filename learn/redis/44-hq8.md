## What this stage teaches

Two invariants make a stream a log rather than a bag: ids strictly increase, and
`0-0` is not a valid id because it is the sentinel meaning "before everything".
Enforcing them is what lets every later read assume order.

It is also your first real **error reply** — a `-ERR …` simple error, which the
client raises rather than treats as a value.

## Go you'll reach for

- Comparison on `(ms, seq)` pairs against the stream's last id.
- `-ERR The ID specified in XADD is equal or smaller than the target stream top item\r\n`
- `-ERR The ID specified in XADD must be greater than 0-0\r\n`

## Hints

<details><summary>Nudge</summary>

Compare `ms` first; only if equal does `seq` decide.
</details>

<details><summary>Approach</summary>

Error messages are compared exactly by the tester. Copy them character for
character, including capitalisation.
</details>
