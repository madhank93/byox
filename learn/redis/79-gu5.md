## Core concept

`LPUSH` inserts at the head, and the ordering catch is real: `LPUSH key a b c`
pushes each element in turn, so `c` ends up first. The result is the reverse of
the argument order, which surprises people every time.

## Go APIs

- `list = append([]string{arg}, list...)` per element, or build the prefix
  reversed and prepend once.

## Hints

<details><summary>Nudge</summary>

Think of it as three separate `LPUSH`es executed left to right.
</details>

<details><summary>Approach</summary>

Prepending in a loop is O(n) per element. Reversing the arguments and doing one
prepend is the same result with one allocation.
</details>
