## What this stage teaches

The RDB file is a binary snapshot, and this is where you start decoding it: a
`REDIS0011` magic string, then a stream of **opcode-driven** sections until
`0xFF`. The two you need are `0xFE` (select database) and `0xFB` (hash table
resize hint), after which key/value pairs follow.

The core primitive is Redis's **length encoding**: the top two bits of the first
byte decide everything. `00` means a 6-bit length in the same byte, `01` means a
14-bit length spanning two bytes, `10` means the length is in the following four
bytes — and `11` does not mean a length at all, it flags a special integer
encoding. That fourth case is the one that breaks naive parsers.

```
RDB length encoding -- the top two bits decide everything:

  bits: 7 6 | 5 4 3 2 1 0
       +----+-------------+
       |0 0 |  6-bit len  |   length is in this byte
       +----+-------------+
       |0 1 |  len hi     |   14-bit length, spans two bytes
       +----+-------------+
       |1 0 |  (ignored)  |   length is the next 4 bytes
       +----+-------------+
       |1 1 |  format     |   NOT a length: a special integer encoding
       +----+-------------+   (0=int8, 1=int16, 2=int32)

file layout:

 +-----------+------+------+------+------+-----+------+
 | REDIS0011 | FA.. | FE.. | FB.. | FC.. | 00  | FF   |
 +-----------+------+------+------+------+-----+------+
   magic      aux    db     resize  expiry  key/  end
                     select        (ms)     value
```

## Go you'll reach for

- `os.ReadFile` — these files are small; read the whole thing and index it.
- `encoding/binary` for multi-byte integers.
- Bit work: `b >> 6` for the type, `b & 0x3F` for the 6-bit case.

## Hints

<details><summary>Nudge</summary>

`KEYS *` returns an array of every key. With one key in the file, that is an
array of one bulk string.
</details>

<details><summary>Approach</summary>

Write the length decoder as its own function returning `(length int, isEncoded
bool)`. Every later RDB stage calls it, and getting the `11` case wrong here
surfaces as garbage five stages later.
</details>

<details><summary>The API</summary>

A missing or unreadable RDB file is not a failure — an empty keyspace is the
correct result, and the tester relies on that.
</details>
