## What this stage teaches

Reading the value, not just the key. A key/value pair in RDB is a **type byte**,
then the key, then the value encoded per that type; `0x00` is a plain string.
Since both key and value are length-prefixed strings, the string reader you
wrote for the key is reused unchanged — which is the point of the exercise.

## Go you'll reach for

- The length decoder from the previous stage.
- A `readString` that handles both the length case and the special-integer case.
