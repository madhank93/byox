## What this stage teaches

When AOF is enabled the server owns a directory on disk, and it must create it
if absent — idempotently, because a server restarts against its own existing
data far more often than it starts fresh. "Create if missing, succeed if
present" is the shape of nearly all startup filesystem work.

## Go you'll reach for

- `os.MkdirAll(filepath.Join(dir, appendDirname), 0o755)` — no error if it exists.

## Hints

<details><summary>Nudge</summary>

Only when `appendonly` is `yes`. With it off, touch nothing.
</details>

<details><summary>Approach</summary>

The directory lives under the `--dir` from the RDB stages, not under the process
working directory. Join them.
</details>
