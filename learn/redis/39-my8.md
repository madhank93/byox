## What this stage teaches

`WAIT <numreplicas> <timeout>` asks: how many replicas have acknowledged
everything written so far? With no replicas attached the answer is 0, returned
immediately as an integer reply (`:0\r\n`) — no waiting, because the timeout
bounds how long you *may* wait, not how long you must.

## Go you'll reach for

- `:0\r\n`, or an integer-reply helper.

## Hints

<details><summary>Nudge</summary>

Count connected replicas. With none, return immediately.
</details>

<details><summary>Approach</summary>

Build the integer-reply helper now; `INCR`, `LLEN` and the sorted-set commands
all use it.
</details>
